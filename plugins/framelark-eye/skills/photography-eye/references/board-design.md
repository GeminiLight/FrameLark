# A 暖纸杂志 · 默认参考板设计

项目用户选定的设计方向。用于把已成立的拍法做成易看、易选的图板；不代替现场判断和照片边界检查。配色、信息层级由 Prompt 指定，完整样板图不是必要输入。生图模型可能改变字体和间距，设计规则不保证逐像素复刻。

## 配色与版心
<!-- knowledge-id: board-design#1 -->

- 暖纸底 `#F3EDE2`；咖啡主字 `#38342E`；可读的褐灰副字 `#71665A`；陶橙强调 `#B56F4B`；提示条浅桃 `#EAD8C3`。编号底可用较深 `#A95F3A` 配柔白字。装饰不改照片白平衡，不给全部题材套橙色滤镜。
- 横向板默认3:2。主推大照片在左约42–46%，右侧四候选2×2；右侧最底部独立提示条。主推适合横幅而不适合左侧通高时，改为上置主图并调整整板比例，不强拉成竖图。
- 以1536px宽为例，外边18–24px、格间16–20px；主推标题约30–34px、候选名字约23–26px、说明约18px。更高分辨率同比放大。主推标题约为候选名字的1.2倍，不能扩成海报大字。
- 清楚的人文无衬线中文字体，名称中等字重，正文常规字重；整体左对齐、编号轻量、边缘和基线齐整。少量圆角、细线即可，不用粗黑报纸体、大色块按钮、厚边框或强投影。
- 照片占主要面积。候选保留各自横竖幅，竖照片用暖纸留边；不能为填格拉伸或切掉指定人物脚部。主图短字叠在实际安静区域；没有安静区域就另留紧凑信息位，不造空墙、抹纹理或遮住关键关系。

### 同排配对与对齐

用户优先要求整排统一、照片边缘齐整，不把每张必须是横幅或竖幅当成独立硬指标。先选成立的照片，再按方向成对安排：优先上排两横、下排两竖，也可上下互换；四张都适合横幅或竖幅时，两排都用同一方向。方幅可成对，避免同排一横一竖各自占不同高度。不要为了两横两竖选弱方案。

每排两个照片窗口同宽、同高、同方向；照片上沿、下沿、标题起始线和间距齐整。两排可以不同高度，两列外框边缘一致。内部照片比例略有差别时，用相等的暖纸留边适配，不拉伸、不裁掉关键关系。需要混合时先调整展示顺序或在不损伤表达的前提下改取景；仍不适合则调整整板布局，保留真实画幅。

首次交付在编号定稿前完成配对。已有P编号时只调布局位置，用槽位表指明哪张在哪一排，不悄悄改编号和名字。生成前明确写上排、下排的编号、方向和统一窗口比例/尺寸，不只给每张各自的画幅。文字仍和真实照片对应。

## 短文案与小帧提醒
<!-- knowledge-id: board-design#2 -->

顶部用小号“FrameLark · 找画面”和短场景名；主图只保留一个主要照片标题。不用“另外四种拍法”作大标题。

P1–P5 编号与图外一致。候选以「名字一行 → 机位/必要设置一至两行 → 后期短句一行」为起点；共用的器材策略可以集中成短行，逐格焦点和动作仍应清楚。设备已知时保留自洽的参数起点，未知时用可执行操作，不为了少字省掉关键角度、改错曝光逻辑或猜器材。具体地标、边界、时机、设置和失败回退放在图外。

右侧底部“小帧提醒”用一至两条、总计约30–50个汉字，告诉用户当前最值得先做或先检查的事：先拍易逝的光；等轮廓间隙；亮部泛白才收曝光；检查倒影边界等。只选由现场或本次说明支持的内容。不要每次固定写黄金时刻、负EV或日落倒计时；地点和日期未知不报钟点。提示与具体拍法一致，不能变成脱离场景的知识格言。

固定 IP 在本 Skill 的 [assets/xiaozhen.png](../assets/xiaozhen.png)。宿主支持图片引用且能读到资产时，实际查看后与场景图同次输入，明确“固定品牌插图，仅放提示条右端”。约占整板宽3–4%，一只、保持原形象、不压字。它是身份参考，不是版式参考；不为插图单独生图。不能引用时仅保留文字“小帧提醒”，不要凭文字重新设计另一只鸟。用户明确要求更换或省略时遵从。

## 可直接填充的设计 Prompt
<!-- knowledge-id: board-design#3 -->

先把场景、五张拍法和逐格短文案整理好，再将以下设计部分与现场约束合在一次请求中。它不包含固定场景、摄影参数或未来光线。

```text
生成一张完整 FrameLark 摄影参考板，默认一张主推加四张候选；输出一个文件。
输入1：用户现场原图，作为真实主体、空间和已有光线的依据。
输入2（如可用）：固定小帧 IP 图，仅作为提示条右端的一只小型插图。
不需要整张版式参考图；设计由下面的文字规范给出。

A 暖纸杂志：暖纸底 #F3EDE2、咖啡字 #38342E、褐灰副字 #71665A、陶橙点缀 #B56F4B、浅桃提示条 #EAD8C3。
左侧约44%为主推大照片，右侧四照片2×2，右侧两排下方留完整提示条。
先锁定槽位：主图=<编号、方向>；上排=<两个编号、同一方向、统一窗口比例/尺寸>；下排=<两个编号、同一方向、统一窗口比例/尺寸>。
优先两横同排、两竖同排，或四张同向；每排照片窗口同宽同高，上下沿与标题基线对齐，两排可有不同高度。
主推是横幅且不适合左侧通高时，改上置主图并调整整板比例，不把横图硬改成竖图。
照片占主要面积；按各自真实横竖幅安排，竖图用暖纸留边，保留要求的四边、头部与脚部；不要拉伸或为齐格改变构图。
1536px宽参考：外边18–24px，格间16–20px。主推标题30–34px、候选标题23–26px、正文约18px；其他尺寸同比缩放。
清楚的中文无衬线字，中等字重标题、常规正文。主推名不超过候选标题的约1.2倍。不用大粗黑衬线字，不堆两块大标题。
顶部小品牌与短场景名；主图字放在真实安静区域，不盖住主体、灯具或有用光影；必要时把说明移到图外。
候选名字、动作/必要设置、后期短句层级清楚，基线、间距一致；详细讲解不塞进图片。
右下方“小帧提醒”：浅桃底、细陶橙左线、一至两条当前场景提示；固定IP约整板宽3–4%，仅一只，不能抢照片或压文字。
底部轻量标注“AI拍摄与精修参考 · 新机位需现场验证”。不要假按钮、厚卡片、强投影、粗边或噪点纸纹。

已经观察到的场景：<可见主体、空间、光线、身份锚点；未知量另列>。
P1 <主推名>：<画幅与边界、真实抓手、动作的效果、成立条件、精修方向>。
P2–P5：<逐格不同拍法、画幅与边界、身份锚点、成立条件、精修方向>。
必须逐字印出的文本：<品牌、场景名、各编号/名称、动作/设置、后期短句、提示和标注；分别列出>。
严格保留：<现场必须保留的物体身份、已知关系、各图的关键边界>。
允许的变化：<各机位、时机与后期分别可改变什么及条件>；不新增<无依据的对象与光线>。
配色只用于图板设计，照片按各自成片意图处理，不全套同一个橙色滤镜。
```

用户提供整张参考板时，单独标它为“仅参考设计”，不把其人物、地标、拍摄参数或小贴士挪进新场景。数量另有约定时随数量调整布局，不为了四格凑拍法。用户已选A后，普通一轮只出一板，不重复展开A/B/C或测试图。

## 生成后检查
<!-- knowledge-id: board-design#4 -->

实际看输出：照片是否压过装饰、字是否可读且有层级、主图标题是否过大、同排方向与窗口尺寸是否统一、上下沿和标题是否对齐、关键边界是否保留、逐格文字是否与真实照片一致、提示是否有依据。再按 reference-visuals.md 核对现场关系；漂亮排版不能遮盖新增建筑或错误机位。

用户未锁定精确比例时，横竖或比例变化不单独判成失败：若关系和四边仍成立、成对排列齐整，可接受并把交付文字改成真实方向，保存原提示与差异记录。若因此切掉脚部、灯具、倒影关系，或把须精确对应的原片框改了，仍按具体内容失败处理。同排一横一竖且边缘参差则记排版未通过，不能只因两张都好看而通过。

分别报告版式与内容的结果。文字Prompt可以复现风格方向，但字体、边距和图窗可能漂移；不要把一次试验称为所有输入下保证稳定。固定IP缺失时不把另一只生成鸟称为小帧。小幅排版变化无需自动连续重抽；必须修正的文字/边界问题按已有修正规则处理并记录额外调用。
