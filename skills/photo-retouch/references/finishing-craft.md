# 精修的正向方法：把吸引力落实到画面

适用：用户要求更好看、更精致，或者几轮修片只有轻微参数变化。先读审美判断，本页补充具体取舍；不是审美打分器，也不是每张都要完成的加工清单。搜索：吸引力、精修、质感、视觉层级、颜色搭配、局部塑造。

## 选片先看吸引力，再看内容覆盖

组图先按 [主题驱动的组图](theme-led-series.md) 形成表达与取舍依据。以下比较发生在符合主题的候选中；单张漂亮也不能自动证明它属于当前组图。主题和素材不匹配时先校准主题，不选完九张后补一个标题。

给照片一个可指认的保留理由：动作或表情、漂亮的光、特别的形状、颜色关系、值得记住的生活细节。不能只说“这张负责咖啡”“这张补绿色”“这里缺一张人像”。同一地点或题材中的比较，先看瞬间和空间组织，再比较基本对焦与曝光。

| 比较情境 | 优先看的关系 | 容易交付的弱片 | 可做的取舍 |
| --- | --- | --- | --- |
| 一组人物活动 | 动作完整、互动、表情、人与环境 | 人物很多但人人低头，主体重叠，背景比活动更醒目 | 比较同事件的时机；独有记忆仍可保留，不把“必须笑”当规则 |
| 咖啡或餐食 | 食物/杯子的形状、受光、材质、桌面关系 | 杯子只是一团黑，食物失焦，大块亮背景无信息 | 找轮廓与质地更完整的帧；收紧或局部试修后仍弱则换备选 |
| 建筑与河岸 | 独特线条、尺度、倒影、前后景 | 主体远且弱、大片平淡天空、杂物与线条争夺观看 | 选结构或光更清楚的帧；留白必须对尺度或情绪有作用 |
| 花草与细节 | 花与叶的颜色、轮廓、透光、疏密 | 好看的花旁有同样醒目的水管、文字或亮墙 | 看另一帧或比较局部构图；有价值的生活痕迹可以保留 |
| 傍晚与夜景 | 天空渐变、灯光、轮廓、安静的空间 | 只有时间不同，画面关系没有变化；强提亮后发灰 | 选择有光色关系的帧，保留夜色；不把“收尾角色”当质量证明 |

组图可以有安静的过渡照片，不要求九张都争夺注意。过渡图仍需有可见的形状、颜色、信息或情绪价值；删掉它只损失“数量”时，重新考虑。朋友圈允许题材多样，选片的审美取舍与事件覆盖要一起完成，不能以同题材替代质量。

## 精致来自视觉层级

在正常分享尺寸看三层：吸引第一眼的锚点、说明地点或关系的环境、让人愿意停留的细节。它们可以是一个人，也可以是两个物体之间的关系。先说出当前由谁主导，再决定要让谁更有分量。

| 目标 | 可试的处理 | 收益应体现在哪里 |
| --- | --- | --- |
| 让主体从环境中分开 | 调整背景的亮度/综合色彩，或主体处的小范围明暗 | 轮廓、动作或形状更好读；不是整张更亮 |
| 让场景有纵深 | 近处留重量，中景可读，远处保留较柔和的对比 | 观看能进入空间；不是每一层都同样清晰 |
| 让细节显得细腻 | 保留材料反射与缓慢过渡，只在需要处增加纹理 | 杯壁、叶脉、织物等有质地，边缘不过硬 |
| 让画面轻盈 | 亮区有呼吸，深色小范围承担锚点，减少无意义的重块 | 光仍明亮，主体仍成立；不是抬黑后全图泛灰 |
| 让画面浓郁 | 集中主色和黑位重量，给肤色/亮部留空间 | 主色更有分量，辅色退后；不是全局饱和度上升 |

需要哪一层变化，便处理哪一层。保留原片里的好关系；变化可以明显，也可以很少。没有吸引力的瞬间不能靠把所有区域都精修一遍补齐。

## 用一套颜色关系组织调色

先读 [光线与色彩](light-color.md) 的白平衡和工具范围，再选择一种画面里已有依据的关系。下面是本 Skill 的处理假设，色彩理论不保证照片漂亮。

| 原片关系 | 可以发展的方向 | 工具抓手与重点 | 容易失去什么 |
| --- | --- | --- | --- |
| 绿叶、灰蓝水面、小面积暖物 | 绿与蓝协调，暖物成为点缀 | 先整理过亮/过艳的绿，保留暖物的颜色与亮度；必要时分别调 green / blue / orange 范围 | 全局降饱和会把点缀色一起抹掉；叶子过分偏青会变假 |
| 米白、木色、咖啡色 | 相近暖色靠明暗和材料分开 | 白瓷保持在现场光下可信，木桌有温度，咖啡和接地阴影有重量 | 把白瓷调成纯白会连带把木色校冷；降反差过多会显淡薄 |
| 粉花、绿叶、浅墙 | 花色有分量，绿叶作承托 | 先判断暖/冷偏色，再通过绿色和局部明暗让花与叶分开 | 本工具没有独立洋红/黄色 HSL，不能声称精确只调花瓣 |
| 银灰建筑、天空与树影 | 材料清楚，天空有空气，绿植作层次 | 金属明暗与反射优先；不要用去雾或饱和度替代结构 | 白平衡偏移会染色金属；过量清晰度会把建筑变硬 |
| 红褐地面与蓝灰暮色 | 暖地面与冷天空保持相对关系 | 保留天空渐变和地面颜色，分别检查高光与暗部 | 全局加暖易使天空污黄；强压天空易变灰块 |
| 暖灯与蓝色环境 | 光源有温度，环境保持夜色 | 不把灯芯与周围光晕调成同亮度；关键轮廓适度可读 | 灯光剪切、阴影蓝紫噪点、黑位被提成灰雾 |

同色系需要明度或质地差别；对比色需要面积和强弱的主次。不要机械规定互补色、青橙、60/30/10 比例或“所有绿色必须降饱和”。邻近色、饱和度差、明度差也可以建立漂亮的关系。基础线索见 [Adobe 色轮说明](https://www.adobe.com/uk/creativecloud/design/discover/color-wheel.html)；表中的题材映射是本 Skill 的解释。

## 通过局部明暗塑造，而非统一加亮

全局关系先成立，再做有位置依据的 dodge / burn：提亮或压暗已有信息，帮助观看路径和体积。当前执行方式是批注绑定的 rectangle / radial / linear 几何蒙版，不是识别人脸、材质或天空的语义选区。

- **杯子、食物、人物轮廓**：主体验证确实偏暗且有细节时，宽缓地提高受光面或轮廓可读性，保留接地阴影。不要让深色杯子变成灰杯子。
- **明亮背景**：必要时减少它的重量，检查墙、天空是否出现灰脏或局部补丁。不能靠压亮把原来没有信息的纯白变成景物。
- **树影与前景**：降低抢眼的局部亮点或轻提必要边缘，不把全部枝叶抬到与主体同亮。
- **天空和地面**：确有不同需要时用渐变分别整理，检查地平线附近的屋顶、树冠与人。渐变不应形成一条可见的暗带。

每次开关局部层看完整画面，再看蒙版边缘。局部存在的理由是改变观看关系；不能因为用户说“精修”就给每张硬加局部。羽化、范围与强度共同决定是否自然，数字较小也可能留下光斑。原理入口见 [Adobe 径向渐变说明](https://helpx.adobe.com/uk/lightroom/web/edit-photos/apply-masks/create-mask-with-radial-gradient.html)，具体实现以本 Skill 的蒙版为准。

## 材质决定细节的分配

| 材质 | 应保留的信号 | 精修方向与复看 |
| --- | --- | --- |
| 皮肤 | 表情、明暗面、真实纹理 | 调整脸与背景关系，少量 texture / clarity 需看毛孔和眼周；不以变白变平为目标 |
| 食物、奶泡 | 形状、湿润高光、细小纹理 | 先看焦点；锐化只改善已有边缘，不能补回失焦；保持食物颜色可信 |
| 金属、玻璃 | 反射跨度、亮边、透射关系 | 高光有过渡，暗面有重量；强压高光和提阴影可能让金属像塑料 |
| 花瓣、叶片 | 透光、渐变、纤维和疏密 | 保留柔软与细节的区别，避免强去雾/清晰度令薄片变厚重 |
| 白墙、陶瓷、云 | 温和层次与现场色光 | 清除有依据的色偏，允许亮区接近白；不用“恢复细节”描述纯剪切区域 |
| 天空、水面、雾 | 平滑过渡、倒影与距离 | 先保护连续层次，不用全局纹理处理给平滑区域加粗糙感 |

“精致”通常来自不同材料得到合适的处理，而非一张统一 texture、clarity、grain 配方。滤镜骨架、逐张适配与局部工艺分开记录；实际输出缩放后再看颗粒、锐度和过渡。

## 从参考学习可以迁移的关系

有用户参考时优先使用；没有参考时可按 [风格图谱](style-atlas.md) 寻找与原片光位、距离、材料和颜色接近的作品。参考必须实际看图，浏览标题或人名不足以完成视觉学习。

把学习缩成四项：哪一层亮、哪一层暗；哪块颜色主导、哪块颜色点缀；主体与环境如何分开；哪里柔和、哪里有质地。最后说明原片具备哪项条件、缺少哪项条件，选择能由现有像素完成的变化。不要把参考中由摄影距离、光线、人物状态或景深产生的效果全部归因于滤镜。

在同一基础上试一个明确方向即可；有合理竞争关系时再试第二个。方向相近则微调强度，方向错误则重做，不用连续叠加相反参数寻找结果。自定义参数配方见 [自定义滤镜与逐张适配](custom-looks.md)。

## 用看得见的收益决定成片

分开查看完整原构图与新构图、同构图的原色与调色、最后实际输出。在正常分享尺寸确认吸引力，在输出细节中确认质地和副作用。至少回答当前真正有关的问题：哪处更吸引人，环境怎样承托，哪种材料更好看，改动牺牲了什么。

“没有明显伪影”“内容多样”“颜色自然”“文件已导出”只回答部分问题。若目标是精致和漂亮，审核还要给出具体的正向收益；看不到时撤掉无益处理、重新选片或保留原片。真实改善不一定比原片更艳、更亮或更干净。当前 Agent 的审美判断与用户接受仍分别记录，不能用 ready 或参考文献代替用户满意。
