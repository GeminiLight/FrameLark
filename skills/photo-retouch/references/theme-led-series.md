# 主题驱动的选片、精修与九宫格

适用：创作型组图、朋友圈九宫格，或用户指出每张和排列都不好看。主题先于正式选片，单图质量与整组成立分别验收。本页不替代活动覆盖、商品真实信息或用户明确必留条件。搜索：主题先行、九宫格、选排、逐张打磨、弱片、精修验收。

## 在正式选片前形成主题方案

已有照片先快速浏览联系表，确认素材能够支持什么表达；准备拍摄时则先写表达，再规划距离、光位与时机。快速了解素材不等于已经选定九张。用户给出的主题直接采用，授权 Agent 决定时自行形成有画面依据的方案，不将判断责任推成风格问卷。

主题方案写清：**表达什么、希望怎样感受、靠哪些可见关系表达、哪些画面值得纳入、哪些画面应退出**。颜色、滤镜和题材是实现手段。地点名、题材清单或“绿蓝粉橙”不足以独立成为主题。

例如“城市水岸的闲暇”可以通过人的停留与活动、岸边空间、阳光树影和有质地的生活细节表达清爽与松弛；纯记录招牌、没有主体关系的杂景、重复而沉重的树框可能退出。这是可更改的示例，不要求每次都拍人、咖啡、建筑或日落。

主题要经素材验证：没有足够的动作、光线、形状或颜色支持它，就在正式选片前修订主题，或说明缺少的画面。不能选完九张后追加一个好听的标题；也不能凭主题虚构人物身份、情绪、天气或时间线。参考作品必须实际看图，从观察距离、主体关系、光色与留白中学习；作者名或滤镜名不会自动提供主题。

主题与入选原片确定后，宿主可按 [AI多图试片与完整精修](generated-reference.md) 一次生成所需数量的精修板；九张可用九格，其他数量按需求排布。每格可以独立裁剪、处理光影、局部与质感。逐格检查后选择原片精修或合适的 AI 精修版本，以实际交付照片决定最终排列；多图板不反向规定题材配额，也不代替选片与完整交付。

## 从符合主题的候选中选出有吸引力的照片

每张入选回答两个问题：它为什么属于这个主题；它本身哪里值得看。第二个答案要指向可见的光、动作、表情、形状、材质或颜色关系。“负责咖啡”“补一张花”“让末行透气”只描述角色，不能完成入选判断。

在同场景、连拍或相近用途的备选中比较具体时机与关系，保留更好的帧。先形成短名单，再从中组织完整组图；不事先给建筑、花、人物、杯子和夕阳各分一格。主题统一可以容纳不同题材、距离和光位，用户要多样旅行分享时，不能把“统一”误做成九张同一对象。

安静的过渡图可以有价值，不要求每张都做强烈封面；它也应有值得停留的关系。创作型精选中，如果删掉一张只损失数量或色块，它应回到备选。用户必留、唯一记忆或记录交付中的弱片可以保留，但要说明用途与代价，不能宣称所有照片都已成为独立佳作。

## 将逐张打磨落实为具体的成片目标

使用 [成片执行卡](finishing-workflow.md) 保存共同观感与每张目标，再决定本地精修、AI 综合编辑或保留原片。先看没有设计包装的实际照片，把照片质量与参考图板的排版质量分开判断。

每张在动参数前写出视觉亮点、目前最妨碍它的关系，以及最终应看到的具体结果。打磨覆盖真正有关的构图、光色、局部、材质和边缘；不以调了多少项、花了多长时间或参数强度证明精致。

| 处理 | 在画面上应完成什么 | 不足以过关的理由 |
| --- | --- | --- |
| 构图与裁剪 | 观看入口明确，主体尺度合适，留白、动势与环境有作用，关键对象完整 | 放大了主体、统一为方形、去掉了更多面积 |
| 光色与滤镜 | 主题需要的光感可见，主辅色有分量，材料与现场光可信；每张适配其光位 | 套用了同款滤镜、色彩较自然、很多小幅改动 |
| 局部塑造 | 该被关注的位置有层次，环境承托主体，过渡不可见 | 提亮了几何选区、阴影数值增加、全图更亮 |
| 材质与细节 | 相关的皮肤、布料、杯壁、花瓣或金属呈现应有的柔硬与反射 | 没有光晕、锐度指标提高、黑物仍是一整块黑 |
| 边缘与输出 | 抢眼边缘得到处理或有保留理由，实际输出的颜色、缩放和细节仍成立 | 文件成功写出、尺寸正确、只看过缩图 |

完整原构图与新构图对照检查裁剪代价；同构图原色与修后检查真正的光色收益。在正常观看尺寸确认吸引力，在对应输出帧的关键区域确认材质与局部副作用。区域图须说明倍率，不能把缩放后的检查称为源图100%。

如果表达希望明亮轻松，但杯子仍堵黑、人物仍读不到、天幕成为无层次的强白块，相关问题就是表达阻碍。只有主题明确需要剪影或强反差、且画面关系确实成立时才保留；“现场本来如此”不足以证明这帧值得入选。具体方法见 [精修的正向方法](finishing-craft.md)。

充分打磨允许大幅或小幅修改，也允许原片已经成立而不改。方向正确才继续细调；细调几轮仍缺少可见吸引力时，在备选中换帧或重新选片，不无限堆处理，不补造失焦、剪切亮部或摄影时机。

## 让精修后的九张进入真实排列

初选时可以试排以检查缺口和重复，正式排列使用实际修后版本。看真实三行三列，也看用户逐张打开时的完整画面；文字角色表和一条序列不能代替九宫格视觉检查。

检查入口和观看重点、每一排及相邻格的明暗重量、主体尺度、颜色面积、方向与疏密。大白天幕、近黑杯体或密集枝叶可能在缩图里比本应关注的人更抢眼；需要实际改变位置、选片或处理。首图和中心没有固定必须承担的角色，暖色三角形、远近景交错也不是自动成立的模板。

排列被用户否定时，比较有不同入口或疏密组织的实际方案，说明取舍再选定；不能只给同一排列换一个解释。排列有潜力但某一格始终拖累整体，应回到单张或备选解决，不能靠邻图衬托把弱片审成合格。

## 单张和整组分别决定是否完成

创作型精选的验收分开回答：

- **单张**：是否符合主题，是否有可指认的吸引力，构图和相关材料是否完成，改动是否真的帮助它。缺少吸引力、主体仍堵塞或构图明显伤害表达，应返修或换片；基本技术可用不能抵消这些问题。
- **整组**：主题是否能被实际照片表达，九张是否有共同气质与必要变化，真实排列是否舒适，是否有拖累整组的弱片。九张单图通过不能自动推出整组通过。

主题、单张或整组中仍有表达阻碍，就如实保留为试修。必要时给出未完成项与备选，不把问题一律改为 minor 来交付。少量方向试片只用于定调；用户要求完整九张时，交付目标仍是完整九张，不能擅自缩成三张或同题材系列。

独立复审同样须检验这些目标。技术检查、参数表、hash、顺序清单和审片者一致赞成都不等于用户满意；不能用 ready 证明审美已经达到极致。用户否定后保留原话与对应结果，将历史判断作为失败线索，从用户实际看到的照片重新检查。

## 已发生的失败与适用边界

旅行九宫格曾按建筑、花、骑行、饮品、露营、彩叶、小车、江船和晚霞分配九格，再用绿、灰蓝、粉橙组织颜色。原片保留、裁剪、逐张调色、局部调整和独立复审都做了；用户仍明确指出每张和选排都不好看，并要求先确定主题再选片、充分打磨每张。具体失败见 [案例与反例](casebook.md#已运行旅行九宫格被用户否定)。

应修正的是主题的实际取舍、单张吸引力和整组验收门槛。该案例不证明所有旅行组必须有同一主题、所有照片必须收紧、自然调色无效或用户永远不喜欢这些题材；也不证明新增规则后的照片已经变好，效果仍需真实成片验证。
