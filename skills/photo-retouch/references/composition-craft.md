# 构图、观看与拍摄选择

## 观看路径与视觉重量

先用缩图判断第一眼，再放大确认第二层信息。视觉重量常来自亮度、色彩、面积、边缘对比、人脸/文字与语义；不能只看物体大小。小面积白灯或红衣可能比大块暗山更抢眼。

可实际问自己：第一眼应落在哪里？现在落在哪里？第二眼能不能理解环境？背景的重复、线条和亮块是否把视线带回主体？没有明确目标时，不把主观排序说成错误。

纠正顺序通常是减少无意义的干扰 → 保留主体/环境关系 → 必要时轻强化主体。暗角不是通用聚焦器；主体靠边或多主体画面强暗角反而错误。

## 空间、边界与留白

- 留白要看方向和用途：目光/动作去向、空间尺度、安静感、排版需求都可能成立。空不是必须填满。
- 检查边缘进入/退出的物体、人物肢体、头顶切线、背景杆线和半个亮物。先判断是否影响表达，再试轻裁；不能为了避免每个切线破坏更重要关系。
- 居中、对称、三分位置只是可选组织。对称空间中的居中人物、极小人物与大环境都有可能成立。
- 前景遮挡可建立距离和窥视感，也可能挡住必要动作。评价它在具体画面里的作用，别一律去掉。
- 近/中/远景的尺度、重叠、清晰度和亮暗形成空间。全部提清晰、去雾可能消除距离；浅景深也不能单靠照片工具制造。

## 线、形与节奏

观察引导线是否通向重要关系，重复是否有变化，曲线是否与动作呼应，斜线是否制造需要的张力。多条线不必都通向同一主体；街头作品可以有多条阅读路径。

要区分地平线歪斜与真实坡面、透视汇聚与旋转。裁剪旋转解决不了镜头视点导致的透视。小幅拉直也可能切掉边缘人物，所以一并查看完整构图。

## 用裁剪重新组织关系

裁剪不是自动居中、套三分法或缩到方形。它可以实质改变主体尺度、明暗面积、线条终点和画面边界。先看完整原片，再比较一个有依据的收紧方案；存在不同表达时再加第二个，不遍历许多随机框。

| 当前症状 | 可比较的构图 | 应保留和复看的关系 |
| --- | --- | --- |
| 杯子小，大块亮天空/墙主导 | 从无信息的亮区收紧，保留杯子轮廓、桌面与环境的一部分 | 杯子有没有更好看，而非只变大；接地、把手和杯口完整 |
| 水岸主体远，空天很多 | 调整天/地面积，让河岸、倒影或线条承担画面 | 留白是否表达距离；不能只剩一条没有节奏的窄带 |
| 花旁水管、杂物抢眼 | 比较花叶关系更集中的范围或另一帧 | 花的枝条与颜色能否成立；干扰位于主体后方时，裁剪可能无解 |
| 建筑和前景同样拥挤 | 保留结构、留出轮廓，删去与关系无关的边缘块 | 曲线/立面是否被切断；前景是否仍有框景或尺度作用 |
| 人物动作不清楚 | 收紧至动作与环境的关系，或选另一瞬间 | 肢体、目光去向、行进空间；放大不创造表情和互动 |
| 极简空间已经安静 | 比较原画幅与少量边缘整理，也可以不裁 | 暗形与留白的平衡；不能因主体小就删除全部空间 |

选择时保持相同光色，完整显示各自画幅；不能只看共同裁剪的 compare 来判断被删掉的内容。收紧后主体失焦、手臂截断、线条悬空或边缘贴死，便调整边界或换片。裁剪的理由是改善关系，比例和保留面积只是事实。

基础原则可参照 Adobe 的 [填满画面与环境保留](https://www.adobe.com/creativecloud/photography/technique/fill-the-frame.html)和 [三分法及其例外](https://www.adobe.com/au/creativecloud/photography/discover/rule-of-thirds.html)；上表是本 Skill 面向具体照片的取舍框架，不是固定构图标准。

## 画幅与像素的双重检查

原画幅、3:2、4:3、4:5、1:1 等都可以试，选择由空间关系和输出用途决定。组图的方格预览与单张发布画幅分别判断；需要方形输出时复看真实裁片，不能为了方格把每张的地点、动作或线条切掉。统一格子不要求所有照片拥有同一种构图。

无旋转时，正向原片宽高为 W、H，归一化裁剪宽高为 w、h，最终画幅比是 `W×w / (H×h)`。目标比例 r 可以用 `h = W×w / (H×r)` 或 `w = r×H×h / W` 求另一个尺寸，再检查 x/y 边界。不是只用 w/h；有旋转时再核对工具的实际几何与导出尺寸。

例如 6000×4000 横图做方形、保留全部高度时 w=2/3、h=1；x 仍要根据主体位置选择。无旋转的保留面积约为 w×h，删掉约四成不要称作“轻裁”。先确认剩余真实像素足够输出，再看主体与边缘细节；越裁越近不保证更好。

## 间隔、姿态与画面的张力

人物关系不仅是“有几个人”：手与物件是否相接、身体方向是否呼应、人物间隙是否让动作可读、静止与移动是否有变化。与相似帧比较，寻找真实瞬间带来的区别；正脸、微笑、完整肢体本身都不能保证关系有吸引力。

简洁也不必抹掉张力：偏心的色块、大小不等的间隔、重复中的一次变化，可以让画面值得停留。复杂图则看不同层是否互相解释，还是都在争抢。留白与遮挡的价值由具体关系决定，不靠“干净”或“艺术感”标签过关。

收紧构图前确认改变的是距离、间隔、形状比例还是信息密度。主体只变大而姿态、受光与空间更局促时，收紧未必更好。相近选择方法见 [审美校准](aesthetic-calibration.md)。

## 多主体与纪实含义

主体可是一组关系而非一个最大物体：对视的人、人物与影子、生产线与工人、云和山的重复。裁掉次要人物可能改变事件含义；如果用户要纪实，先保护关系、地点和动作证据。

对复杂场景，可以通过明暗/颜色建立轻重，未必需要裁掉复杂性。若现有像素确实无法解决严重重叠，坦诚给下次拍摄建议，不假装局部增亮能改变物体位置。

## 从修片反馈到下一次拍摄

只有用户希望学习或现有像素难以解决时，给一个具体练习：

- 头顶背景切线：拍前左右移动一小步，观察轮廓是否分开，而非“遵循三分法”。
- 人脸与窗外亮差太大：改变人物朝向/位置或补光，保留窗景是否必要由意图决定。
- 前景关系太乱：比较更高/更低机位或等待人物分开，而非默认长焦压缩所有场景。
- 主体软：区分焦点、快门与景深；器材/参数未知时先问或讲判断方法，不编造拍摄参数。
- 画面没有情绪变化：考虑距离、瞬间、光线与选片；不是继续加饱和度。

反馈写成可以当场做的动作和观察结果。一次只强调最有价值的一项，不把每次审片变成摄影课。
