# 自定义滤镜与逐张适配

适用：用户让 Agent 自己选滤镜、希望自定义风格、内置预设不适配，或要复用一组照片的综合色调。搜索：自定义滤镜、自定义配方、强度、色调、选滤镜、custom look。

## 三种可用方式与真实能力

1. **内置风格**：用 `controls` 返回的真实 id 和 0–100 amount；当前有 14 款。风格层独立，手动层用于适配照片。
2. **自定义配方**：用现有调性、HSL 与质感参数组合出自己的方向，保存为有名称、有适用条件的 JSON 记录，再编入 `candidate.settings`。可以完全不用内置预设。
3. **逐张精调**：在选定方向上调整曝光、白平衡、局部光色、裁剪与细节。它们是这一张的处理，不应一并复制给所有照片。

本地 `style` 目前只接受内置 id；自定义配方写进手动参数，不是注册任意新 style id。没有外部 LUT / XMP 导入、胶片扫描校准、任意 RGB 曲线、色轮或独立洋红 HSL。能够自定义组合参数，不能据此宣称具备这些功能。Adobe 的 [预设文档](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/apply-presets.html)说明了保存选定调整的思路，本 Skill 使用自己的 JSON 和参数语义。

按摄影师名选择时先查 [风格参考库](photographer-library.md)。可以以他的作品语言为主线再自定义适合当前照片的参数，不将人名写成未注册的 style.id；保存具体参考与处理依据。

## 先选关系，再选滤镜

如果难以仅用文字确定目标，宿主可用 [AI多图试片与完整精修](generated-reference.md) 按所需数量一次预演综合精修，包含裁剪、光影、局部与质感，而非只加滤镜。本页负责可转为本地配方的光色部分；采用 AI 精修成片也是可选交付方式，不必全部复刻为参数。不按生成图均值倒推配方，也不把重画细节称为原片恢复。

| 原片条件与目标 | 可以选择的骨架 | 应自行处理的部分 |
| --- | --- | --- |
| 日光、人物/生活，想清爽但有分量 | 自定义自然反差；daily-soft 仅在柔和关系合适时试 | 肤色与白物、主体阴影；原片偏平时不再减反差 |
| 有木色、米白、咖啡，想温润 | 自定义暖色与深色锚点；quiet-film 可作方向比较 | 白瓷、木桌、杯中高光；不把温润理解成全图泛黄 |
| 绿植与水岸，想有纵深 | 自定义绿色/蓝色关系，保留暖点缀 | 不同距离的明暗、天空与水面；不默认全局降色 |
| 银灰建筑或极简场景，想利落 | 自定义中性调性与结构；misty-air 仅在雾感有依据时试 | 材料反射、亮部、构图边界；阴天不自动等于低对比 |
| 花草、逆光小景，想轻盈 | luminous-poem 或自定义高光与主色 | 透光和背景；检查花瓣是否失去颜色或高光层次 |
| 暮色/夜景，想有气氛 | blue-hour、cinema-night 或自定义冷环境/暖灯关系 | 灯芯、暗部噪点和关键轮廓；不用白天配方同步曝光 |

这是适配入口，不是按题材自动套滤镜。相近的两张照片可能需要不同骨架，不同题材也可以共享同一套调性。用户已让 Agent 选择，就基于画面作出可撤回的选择，不反复让用户填风格问卷。

## 设计并保存自己的配方

先在一张具代表性的照片上确定意图、材料与主辅色，试成片后再命名。保存配方名、适用光线/材料、要保留的关系、所含参数和撤回条件；名字描述真实观感，不以“高级”“大师同款”替代依据。当前 recipe 记录由宿主保存，不存在一个自动注册配方到滤镜菜单的命令。

复用时区分三类内容：

- **可共享的骨架**：调性倾向、主辅色关系、有限的质感选择；参数也需逐张验证，不保证相同数值同观感。
- **每张适配**：曝光、纠正偏色的白平衡、高光保护、降噪和输出锐化。创意冷暖可以属于骨架，但不能把某张的偏色补偿误学成风格。
- **位置相关**：裁剪、旋转、批注及局部坐标。单独记录，不复制为通用滤镜；它们不能靠配方名获得语义自适应能力。

已有内置风格时，检查 `edit-sources`（运行时具备该命令才用），区分风格贡献和手动适配。需要独立的自定义方向时，基于明确选定的中性/获准重建基础；不得为试滤镜清空用户接受的局部、保护或裁剪。保留内置风格的情况下，自定义手动值只写所需适配，不再复制预设中的相同配方。

## 可执行的自定义试片起点

以下三个 `patch` 是针对**手动参数全零、没有风格层**的基础设计的教学起点，不是万能滤镜或已获用户认可的配方。使用前实际看原片，修改或放弃它们；正式方案填 `inspect` 的最新 revision 和基础版本。非零基础不能直接套下列绝对值并称为相同效果。旧失败方案要按获准范围重建，不能靠未写的参数自动清空。

### 自然反差：保留白物、深色与主色

适用：已有日光和清楚主体，但调性偏平的生活/建筑照片。通过较明确的黑位与中间调建立分量，蓝绿只做少量整理；没有理由降绿色时删除相应参数。

```json
{"style":null,"settings":{"contrast":9,"highlights":-10,"shadows":8,"blacks":-5,"curveMidtones":3,"vibrance":5,"greenSaturation":-7,"blueSaturation":-3}}
```

看主体是否更好读、白物是否有层次、黑色是否仍有细节。若原片已硬、黑位已堵或表情变重，改小或放弃这套关系；不是追加 fade 抵消全部反差。

### 温润静物：暖材料与细腻高光

适用：暖木、陶瓷、咖啡等已有温暖光线的静物。温度来自材料关系，少量暖色只支持它；白物过黄时先撤回 warmth，不把木色一并校成冷灰。

```json
{"style":null,"settings":{"contrast":5,"highlights":-12,"shadows":6,"blacks":-4,"warmth":4,"orangeSaturation":3,"blueSaturation":-5,"texture":3}}
```

看杯壁/奶泡的过渡、木材颜色、深色与接地阴影。原片已经漂亮可保留；失焦食物不因 texture 参数出现而变得可交付。

### 冷暖暮色：保留亮灯与夜色

适用：蓝调环境里已有暖灯的画面。让环境与灯保持区别，强度由当前蓝色、灯和暗部决定；没有暖光源时不机械套用。

```json
{"style":null,"settings":{"contrast":8,"highlights":-14,"shadows":5,"blacks":-4,"warmth":-4,"blueSaturation":4,"orangeSaturation":5}}
```

看灯芯是否仍亮、环境是否保持夜色、肤色和阴影是否变蓝紫。不用大幅 exposure 提亮把整个画面抬平，也不用 grain 掩盖噪点。

2026-10-04 实际试片中，这三套参数均能通过当前候选工具渲染，但并非三张都值得采用：教学人像的背景与黑色物体更重，脸部收益有限；咖啡样片原来已有暖木和清楚的杯盘，新增暖色与纹理未显示必要收益；夜景仍保留冷暖，但变化较小，不能贴上新名字就称为明显改善。咖啡的另一份裁剪虽集中杯盘，下缘却过近，需要回退边界。以上是这三张低分辨率教学照片的宿主自审，不是一般审美评测，也不是用户认可；可执行配方不等于适配配方。

将按当前画面改好的 patch 放入现有候选结构，例如：

```json
{"revision":12,"baseVersion":"实际读取的基础版本ID","name":"温润静物·保留木色","goal":"杯子形状清楚，白瓷和木色有层次","tradeoff":"让背景退后，保留桌面的现场信息","items":[{"id":"custom-color","title":"自定义光色","patch":{"style":null,"settings":{"contrast":5,"highlights":-12,"shadows":6,"blacks":-4,"warmth":4,"orangeSaturation":3,"blueSaturation":-5,"texture":3}}}]}
```

这里只演示全局方向；裁剪与局部如果需要，分别加入有效项目。不要把配方记录中的名称、条件等额外字段传入 patch，不要编造 style.id 或批注 ID。

## 自定义强度与绝对目标

内置 amount 由引擎处理。手动配方没有独立的强度滑块；宿主从**同一固定基础**生成不同参数目标：`目标 = 基础手动值 + 强度 × (完整试片目标 − 基础手动值)`。只插值本次配方控制的键，检查范围；其它参数和层按获准范围保留。该公式调整参数强度，不保证视觉响应线性，也不等同于两张成片的像素混合。

例如从 contrast:0 的固定基础到目标 10，50% 试片写 contrast:5。下一次 80% 写 contrast:8；不是在 5 上再加 8。`settings` 始终是绝对目标，`fromCandidate` 会继承现有各层，不能把同一配方重复相加。用到同一个 settings 路径的修改合并到一个 item，避免写入冲突。

先比较明显但合理的完整方向，再回调到材料与空间可信的强度。不是从极小数值开始就一定精致；不是达到某个百分比就自动审美过关。若需要大幅相反参数才能挽救风格，优先改骨架。

## 与构图和局部一起完成精修

裁剪改变画面的空间关系，滤镜改变明暗与颜色，局部处理决定注意力的分配。先识别最大的阻碍，再试最有价值的变化；不用固定“先滤镜后裁剪”顺序绑住每张照片。比较颜色时保持同构图，比较裁剪时保持同光色，最后复看完整组合。

选定方向后，逐张看 [精修的正向方法](finishing-craft.md) 中的层级与材质，再读 [细节与局部工艺](detail-local-crop.md) 核对实际范围。批次先用代表不同光线/材料的照片检验方向，白天、室内与夜间允许不同强度和适配；保持题材变化与现场关系。保存滤镜配方不等于所有照片都需要它。

审核填写具体的正向收益与代价。对照片好看的判断、工具执行成功、用户接受是三件不同的事。配方或基础变动后重新看图，不沿用旧 ready。
