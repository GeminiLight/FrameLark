# 从一批照片到一组作品

## 用途先行

| 拍完之后要做什么 | 选片标准 | 排列与处理重点 | 交付 |
| --- | --- | --- | --- |
| 旅行、生活随记 | 记忆点、人物关系、场景变化；技术一般的独有瞬间可保留 | 环境—人物—细节只是候选节奏，保留当地光线差异 | 有封面和阅读顺序的分享组；未选照片保留 |
| 人物、情侣、家庭交付 | 表情、互动、姿态、对焦；用户指定人物和瞬间优先 | 同光位匹配肤色；不把所有肤色拉成同一种，不抹平面部结构 | 精选组与备选；不默认美白、磨皮、瘦身 |
| 活动、婚礼、纪实记录 | 关键环节、人物覆盖、独有信息与情感价值 | 时间关系仅按用户或可靠记录确认；覆盖重要环节比漂亮滤镜更重要 | 可分章节的交付组；不改写发生的事实 |
| 街头、摄影叙事 | 主体关系、重复母题、留白和信息增量 | 可以按视觉或情绪排列，说明这是表达建议；避免每张都成为高潮 | 主题组、备选和排序理由 |
| 商品、餐饮、房源 | 真实颜色、信息完整、角度互补；瑕疵与关键规格不能掩盖 | 以代表性的中性参考匹配；准确性优先于情绪滤镜 | 主图、角度、细节、环境；是否加字另行确认 |
| 作品集、参赛候选 | 独立作品质量与整组非重复性；不强凑数量 | 先建立短名单，再检查强弱与重复；不同项目可分组呈现 | 精选、备选和未入选理由；具体投稿规格须另查 |
| 打印、相册、家庭归档 | 情感与覆盖；保留完整事件和原片 | 相册翻页与留白需要实际版式工具；印刷另核尺寸与出血要求 | 编号照片与项目记录；本工具不做印厂软打样或相册 PDF |

“全部修好”不等于“替我删片”。选片状态只是清单，工具不删除源文件。没有发布目标时，不强行套社交平台模板；没有叙事需求时，不给商品目录编旅行故事。视频、Live Photo、RAW、HEIC 或印刷版式，先核实能力并分流，不能把静态照片工具说成全格式流水线。

## 主题与最少追问

创作型精选先按 [主题驱动的组图](theme-led-series.md) 写清表达、观看感受与纳入/退出依据，再正式选片；主题贯穿逐张精修和真实排列。不能用题材配额或配色名替代它，不能先留下九张再补主题。单图吸引力与整组成立分别检查，详细成片标准和九格空间检查见该页。

先实际扫看一页照片，再决定是否需要问。用户已经给出“这次海边旅行，选六张，轻松自然”时直接建立 brief。用户只说“修好这些”，用途会影响取舍时问一个问题，例如“你想全部留作记录，还是精选一组分享？”；只说“高级”时可问“更想保留现场感，还是让色彩更克制？”不要一次发一整份问卷。

整理四件事：用途；一句话主题或表达意图；目标数量（可以未知）；必须保留的照片/人物/事件及不能改变的关系。目标数量是期望，不是填满配额。意图不清但不会改变初选时，先做可撤回的短名单并说明假设。

主题须能改变决策：哪些信息属于它，哪些重复或偏题，什么关系值得留下。“电影感”不足以证明必须偏青或压暗；“一天的旅行”也不证明能从光线猜出准确时间。用户主题优先于历史风格偏好，但主题和画面冲突时指出差异，给出“调整主题”或“换用备选”的具体选择，不虚构故事。

`purpose` 与 `sequence` 分别保存用途和排列依据；`theme` 保存当前表达，`constraints` 保存保护条件，`mustKeep` 保存明确必留的稳定 ID。更改主题会使旧取舍过期；保留旧方案作为历史，不自动覆盖当前编辑。

## 大批量初选与细看

1. `collection-init` 创建独立组图项目，读取 `imports` 中逐个失败原因。先处理可用照片；失败文件不能被算作“已审阅”。目录导入不递归，最多 500 个文件；更多照片分批并维持总清单，不默默截断。
2. 用 `collection-sheet` 逐页查看，每页至多 20 张。稳定编号 P0001 等用于一切取舍和排序，文件名仅作定位。工具只画缩略图，宿主视觉模型负责理解主体与表达。联系表不是细节质量证明。
3. 第一遍辨认题材、场景和可能的重复组。第二遍打开候选单图，检查构图、表情和光线；对连拍、眼部焦点、运动模糊、噪点和过度锐化，用原图/准确输出帧裁片检查。无法确认的照片留作 reserve，不装作已经检查过。
4. 比较相似画面时考虑表情、动作、边缘干扰和独有信息。`duplicateOf` 只提示文件字节完全相同；没有提示不表示画面不重复。工具不会根据文件名、平均亮度或锐度排名自动筛掉照片。
5. 每张已看照片记录：可见观察、选/备选/不入选、对应主题的理由、应保留的关系、叙事作用。未看过的照片不填决定，`unreviewed` 会明确显示。技术瑕疵与偏好分开：唯一的情感瞬间可能值得保留；漂亮但重复的画面可能不入选。

部分审阅可以保存；交付前说明审阅范围和未看数量。首次批量操作先小批跑通，不在尚未检视的全部照片上复制裁剪、画笔或人像局部坐标。题材差异明显时提议拆成多个组，并保留用户的最终选择。

## 选片与阅读顺序

用“必要信息是否齐全”和“每张增加了什么”检查短名单，不用一个审美总分替代取舍。考虑用户必留照片、场景/人物覆盖、相似帧冗余和风格差异；同场景连拍可以推荐一张并把其他放入备选。目标六张却只有四张成立时，交付四张并说明缺少什么，不自动填充两张弱片。

排序有四种依据：

- **视觉**：主体大小、明暗、色块、方向和远近的呼应。允许变化，避免连续几张同尺度同构图。
- **时间**：用户确认的实际事件先后。文件名序号或日落光线不构成可靠时间证据；没有依据时保留导入顺序并说明。
- **情绪**：轻重、停顿、张力和结尾的余韵，不等于不断增强饱和度。
- **手动**：尊重用户已排的顺序；如建议调整，先给理由和预览，不悄悄重排。

首图应能代表整组并建立进入点，不一定是色彩最强的一张。环境、主体、互动、细节、过渡、收束是可用角色，不是每组必有的六格模板。商品系列按信息需求排，纪实组按事实关系排。用户说“封面用这张”时，将它列为必留并放在 order 首项；必留只约束入选，工具不会自动决定其位置。

组图方案的 `order` 恰好包含全部 select ID，各一次；reserve/exclude 不导出但仍在项目。`anchorId` 选代表性光线和颜色的入选参考，不默认首图也是定调参考。若无共同定调价值，可以为空。

## 统一观感与逐张修片

先在一张代表性照片上建立可预览的定调候选，说明希望保留与改变什么，再选一张困难照片检验该方向。夜景、逆光、肤色与高反差常暴露过度统一的问题。只有用户接受或已明确授权自动完成时才接受版本。

把统一分成三层：

- **共同约定**：颜色倾向、对比方式、黑位、颗粒和锐化观感；可以不需要共同预设。不是所有照片必须同直方图、同白平衡。
- **按光位匹配**：室内外、日夜、不同光源可以分别定调。肤色、中性色、天空过渡应自然，不能把夜景提成白天或强行消除夕阳暖色。
- **逐张例外**：曝光、白平衡、高光、局部亮度、裁剪和细节按每张实际画面判断。允许零调整。局部坐标和裁剪不跨图盲复制；保护锁和最新批注仍有效。

单图 `settings` 为绝对目标；独立 `style` 层不再抄进 settings。根据当前版本设置目标，不重复补偿之前已接受的曝光和饱和度。`collection-inspect` 给出单图项目路径；进每张项目重新 `inspect`，基于最新 revision/currentId 试片、看图、接受。组图方案不直接接受任何修片候选。

接受新版本后旧组图方案会标成 stale。重看最终联系表和关键单图，用新 snapshotHash 保存确认后的取舍/顺序；可以保留相同顺序，但不能仅为消除 stale 标记而跳过复看。最后同时检查单张完整构图与整组阅读节奏，指出统一方向的代价，而不是只报告参数已同步。

## 分支、反馈与交付

用户想比较“自然”和“胶片”时，使用各单图命名版本；组图取舍可另存新方案，不能覆盖满意版本。用户替换一张或修改主题后先判断影响范围：单张光色可以局部修正，叙事角色改变需要复看前后相邻图，共同定调变化需要检查代表图与困难图。

完成时交付：主题与用途摘要；已审阅范围；编号顺序、每张角色和保留理由；备选与不入选理由；实际导出文件、尺寸与限制；尚待检查的地方。让用户能说“把 P0004 换成 P0011，色彩更自然”，不用重新描述整批文件。

`collection-export` 按最新方案导出已保存版本，用编号文件名和 manifest 对应顺序、主题、版本、文件校验与逐张状态。失败不会阻塞其他照片，重试保留成功文件；已输出文件被改动时不覆盖。默认不上传、不发布、不删除备选；用户要求加文字时另走独立文字模式，确认文案、留白与整组层级，不每张默认加字。

主题、联系表、照片项目和审片记录保存在本地组图目录；宿主模型是否接收照片仍取决于宿主。技能没有跨用户训练或自动跨项目画像。反馈可记录哪种取舍/风格被接受及其适用条件，当前创作目标仍优先。

## 情境验收

| 输入情况 | 应怎样完成 | 应暴露什么问题 |
| --- | --- | --- |
| 60 张旅行连拍，“选一组轻松随记” | 看完三页；细看候选；问数量仅当影响交付；保留记忆点与变化 | 不能声称未看的后两页已审核；不重复选同一瞬间 |
| 一张模糊但独有的家人合照 | 说明技术代价，考虑情感用途并保留备选/必留 | 不按锐度阈值自动淘汰 |
| 日间、夕阳、夜间混合，“统一” | 按光位匹配共同倾向，保留昼夜差异 | 不拉成同亮度；不凭天空编准确拍摄时间 |
| 用户指定六张但只有四张符合主题 | 交付四张短名单、可选备选与缺失信息 | 不为凑数虚构优点；数量偏差明确 |
| 商品目录与创作风格冲突 | 优先真实颜色和信息，说明滤镜代价 | 不将色彩失真包装成高级感 |
| 已选片后更改主题或批注 | 原方案标过期，保留原版；重新评估受影响照片 | 不能导出过期方案或绕开保护条件 |
| 第三张导出失败 | 第一、二张保留，记录失败，恢复后只重试失败项 | 不清空整组；不覆盖已有文件或暗中发布 |

这些是行为检查标准，不是自动审美评分。先用有来源的真实照片和用户明确意图验证结果，再扩展知识；软件测试通过不等于选片与修片质量通过。
