# 光线、色彩与层次

## 曝光分诊

先找光源、主体受光面、反射和遮挡，再判断哪些亮暗关系影响意图。直方图是像素分布，不能说明人脸必须提亮或夜景必须有中灰。

| 画面症状 | 先验证 | 最小处理方向 | 保留与检查 |
| --- | --- | --- | --- |
| 全画面沉闷，主体和背景都缺少可读层次 | 是否本来就是低调表达，阴影有无真实细节 | 少量 exposure，再观察中间调；必要时小幅 shadows | 亮部是否变平，灯光是否失去强度 |
| 天空合适，人物太暗 | 人物是否应可辨，人物与背景是否能分开 | 优先人物局部或小幅 shadows | 逆光轮廓、黑衣黑发、背景噪点 |
| 白云或白衣层次过硬 | 原图通道是否已剪切，还是对比过高 | 先回退此前曝光/对比，再试 highlights | 不能把纯白区域说成已恢复纹理 |
| 黑位堵塞 | 黑色物体本身与可恢复暗部是否混淆 | 小幅 blacks / curveShadows，必要时局部 | 接地阴影要有重量，不能全部漂灰 |
| 雾景发灰 | 雾是否是空间和情绪的核心 | 常可保留；仅增强需要辨认的近景 | 远山层次、雾的亮度，不把 dehaze 当清晰度总开关 |
| 强光照片看起来平 | 是否前次高光压得过多 | 减少压缩，保留明暗跨度 | 光源可以亮，反射可以接近白 |

曝光控制用于已有像素的映射，不是重新拍摄。当前引擎有柔和亮部压缩，但无法补回 JPEG 内不存在的信息。先看上次修改来源，避免再次补偿同一问题。

## 光形与材料感

除了曝光是否合适，还要看光怎样落在物体上：方向、受光面积、阴影边界、反射形状和亮到暗的过渡。选择或精修的收益可以是体积、薄透感、湿润感、空气感或漂亮的光影图形；“更亮、更通透”没有说明这些关系。

| 真实光线条件 | 值得发展的关系 | 处理取舍 |
| --- | --- | --- |
| 侧光落在杯壁、脸或建筑上 | 受光面与暗面共同说明体积 | 保留两面的分量及接地阴影；把所有暗面提到同亮度可能变平 |
| 叶片、布料或玻璃已有透光 | 透光处的渐变、边缘与相邻暗形 | 保留透与不透的差别；全局清晰度容易让薄材料显厚重 |
| 柔光下的皮肤、白瓷或浅墙 | 宽缓但可读的过渡，以及不同材料的细微区别 | 不用压高光把亮物压灰，也不因柔和就统一抬黑 |
| 强日光产生投影或亮边 | 光与影的形状、方向和间隔 | 阴影可能承担构图，先判断再提亮；增强形状时检查硬边与高光损失 |
| 金属、饮品或食物有真实反射 | 反射位置与形状帮助读到材料 | 宽缓地整理已有层次；不能把普通亮斑都当瑕疵抹平 |

同一题材内选片时，可优先比较上述关系更成立的帧，不等修片才寻找好光。调色与局部能够重分已有亮暗，无法创造原片没有的光向、透射或漂亮反射。原片是平光并不自动弱，颜色、形态和瞬间也可能成立；重点是当前想发展的价值是否真的可见。

## 白平衡、肤色与混合光

- 中性物必须真是中性：白墙可能被暖灯照亮，婚纱可能有米色，雪可能反射蓝天。找两个以上线索，无法确认就保留色光并说明不确定。
- 先区分 **整体偏色** 与 **局部光源色**。夜景霓虹、日落、舞台和烛光不应该被强行中和；不同光源下单个全局白平衡不一定能同时成立。
- 肤色判断比较同一人物的脸、颈、手和明暗面，检查是否出现通道剪切、黄绿斑或过量洋红。尊重原来的肤色深浅，不能用提亮当美化。
- 当前 warmth / tint 是相对通道增益，非 Kelvin / Duv；不要把“5500K”直接写入参数。warmth 正值更暖、负值更冷；tint 正值减绿／向洋红，负值减洋红／向绿。先读 controls 的真实响应；校正绿偏不能给增加绿色的方向。绝对目标值要与所选基础版本比较，不把目标负值一概当作减少。修正一次后重新看肤色和白物，不能只凭方向断言画质正确。
- orangeHue / orangeSaturation / orangeLuminance 是颜色范围操作，同时影响木材、橙衣、晚霞。想改脸而背景应保留时，应优先局部；当前几何范围仍需检查是否碰到背景。

## 色彩关系

色彩的价值在关系：主色占比、邻近色过渡、点缀色位置、明度差以及观看顺序。先指出“人物红衣与灰蓝山脉构成焦点”，再决定是否改饱和度；不能只说“更通透、更高级”。

- saturation 广泛改变颜色；vibrance 的相对保护不是可靠的肤色隔离。两者都要看人脸和高饱和物体。
- 颜色显脏可能来自曝光、不同光源或相邻色冲突。先解决光和层次，再试整体加色。
- 颜色显艳不等于越饱和越好。降低干扰色、保留主色，常比全局增色更有效。
- 色相变化必须比较物体的可信性。绿色叶子发青、天空偏紫、肤色橘化时回退，除非当前意图明确需要这种非自然表达。
- 输出黑白前先判断颜色承担的叙事：红色救生衣、交通信号、两种服饰可能因灰度接近而失去区别。当前 monochrome 是灰度混合，没有独立彩色滤镜混色工具。

## 中性基底与画面适配

用户让 Agent 自己选风格时，依据画面里可见的光、材料与色彩面积做选择：日光绿植可让自然绿色承担主色、小面积暖材料形成锚点；夜景保留灯与环境的冷暖；人像先保证肤色与背景的关系。说清适配理由，风格名和摄影师名字不代替实际关系。用户已交给 Agent 选择时，不重复让用户填风格问卷。

“中性”表示材料在当前光下可信。米黄墙、砖色、铁锈、蓝天反射不能强行变灰；白物也不必所有像素 RGB 相等。先实际查看至少两处有依据的参照，排除剪切白、染色玻璃、混合光及取样里的窗户/杂物，再判断全局偏色。局部 RGB/色差统计只辅助定位，不证明已做灰卡校准，不作为审美分。

综合色调先形成一个基底，再用 HSL 整理主辅色，并按真正需要添加局部光色。绿色降饱和后发灰时，要重新检查白平衡、明度、色相和邻近颜色；不能继续全局降饱和。阴影要有重量，亮部要有材料感，天空与水面的相对冷色须和暖色主体一起复看。

被拒绝的 Agent 试修如果经过多次补偿，先读取所有层，明确重建范围。`settings` 和局部 `settings` 未写的键都会继承；把同一 annotationId 再写一次不等于替换整个局部。需要清空 Agent 自己的失败局部时，先建 remove:true 的可撤回基底，再从该基底候选用 fromCandidate 编译完整新目标。已接受的用户调整和保护条件仍按当前约束处理，不用重建绕过。

色彩审核至少检查：参照材料是否可信、主辅色是否帮助观看重点、暗部是否脏堵、亮部是否偏色、局部是否仍含无意继承的补偿。色彩未达到目标时记作 revise，即使裁剪或技术检查通过也不记作整张完成。

## 曲线与质感的区别

contrast 改整体跨度；curveShadows / curveMidtones / curveHighlights 提供宽范围的调性倾向，不是任意控制点曲线。先决定要在哪个明度区建立层次，再试一个方向，勿同时堆叠对比、黑位、曲线和去雾而无法解释来源。

fade 抬黑会减少黑位重量。负片、柔光、怀旧都不要求漂灰；高光柔和与黑位泛灰是两件事。局部 texture / clarity 改微反差，也不等于真实分辨率提升。加 clarity 后先看脸部和高反差轮廓，再看整体。

## 与实际工具对齐

执行 `controls` 取得当前范围，以下名称只是检索入口：

- 基础调性：exposure、contrast、highlights、shadows、whites、blacks。
- 色彩：warmth、tint、vibrance、saturation、三个颜色范围的 Hue / Saturation / Luminance。
- 层次：curveShadows、curveMidtones、curveHighlights、fade。
- 细节与气氛：texture、clarity、dehaze、sharpen、denoise、grain、vignette、monochrome。

风格是独立层。先处理确实需要的基础问题，再低强度试风格；在风格已经存在时调整手动层的绝对目标，不照抄风格配方。触到工具范围后不能承诺继续加数值仍产生相同收益。

参考：Adobe 的 [Camera Raw 锐化与降噪说明](https://helpx.adobe.com/ca/camera-raw/desktop/using/sharpening-noise-reduction-camera-raw.html)用于理解细节检查；本 Skill 的参数语义以自己的 `controls` 和引擎为准。这不是 Lightroom 参数换算表。
