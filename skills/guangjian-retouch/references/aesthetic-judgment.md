# 审美判断：先确定画面为什么成立

适用：首次审片、用户说“更高级”“不够好”、建议之间发生冲突。搜索：意图、视觉重点、保留、叙事、参考图、取舍。

## 判断次序

**表达目标 → 叙事关系 → 视觉秩序 → 光色关系 → 技术瑕疵 → 输出用途。** 这是判断依赖，不是要求逐栏打分。技术缺点可能值得改善，却未必值得牺牲表达。用户选择优先于本 Skill 的默认口味。

- 表达：画面想让人感到什么？亲近、疏离、安静、紧张、轻盈或厚重，要有可见依据。
- 叙事：主体和环境如何互相说明？人物、光源、地点、动作、视线、前后景不能随意裁掉。
- 秩序：第一眼落在哪里，第二眼去哪里？边缘亮点、颜色孤岛、切线、重复形态是在支持还是抢夺注意？
- 光色：光源方向、冷暖、亮暗和材质是否一致？“更亮”与“更清楚”是两个目标。
- 技术：剪切、偏色、噪点、光晕、色带、涂抹和失焦，分别在哪个位置影响观看？
- 用途：纪实、肖像、商业、作品集、手机分享或打印，允许的调整和细节强度不同。

## 六个观察维度

| 维度 | 看什么 | 不应误判 | 提建议前需要的证据 |
|---|---|---|---|
| 主体关系 | 主体尺度、表情/动作、主体与环境 | 主体小、人物背影或剪影并不自动有问题 | 指出主体怎样被背景或光线压住，以及意图为何需要改变 |
| 构图空间 | 边界、视觉重心、留白、层次、视线去向 | 三分法、居中、对称都不是评分规则 | 完整原构图与候选裁剪对照；说明被删除的叙事元素 |
| 视觉秩序 | 明亮区域、色块、线条、重复、重叠 | “复杂”不等于“杂乱”，多层街头可能需要复杂度 | 标明干扰位置，证明它确实转移了用户想保留的重点 |
| 光线层次 | 主光、辅光、暗部、反射、高光过渡 | 夜景暗、高调亮、逆光黑不是天然缺陷 | 看主体/背景分别的可读性，分辨可恢复信息与纯剪切 |
| 色彩关系 | 主辅色、肤色、局部光源、色彩面积 | 暖灯下的皮肤不应强行中性化；没有单一“正确肤色” | 可辨认的光源、可靠中性物与同一光线下的材料关系 |
| 情绪表达 | 光色、距离、节奏和意图的一致性 | 清晰度和饱和度提高不等于情绪更好 | 说明调整如何改变观看感受，并给出适用条件 |

不用伪精确的审美总分。确需参考分时，说明它是对当前意图的主观比较；本地亮度统计不能填充主体、构图或情绪分。

## 将判断写成可验证的假设

建议用：**可见事实 → 对当前意图的影响 → 最小处理 → 检查点 → 代价**。

例如：“人物的黑色背包与近处山体合在一起；若希望读到轮廓，可只在这处轻提阴影。检查背包与岩石的分离，同时保留逆光的暗色关系。”

避免：“人物曝光不正确，整体曝光 +0.8。”前者允许通过局部对照验证，后者把解释当成事实。

诊断通常先告诉用户一两处值得保留的关系，再给真正有收益的变化。数量由画面决定。不要为了覆盖六维或让回答显得专业而凑建议。

## 常见审美冲突

- **安静 vs 清晰**：小幅局部整理可以保留雾感；强去朦胧可能摧毁安静。
- **真实 vs 风格**：风格可以有偏色，但人物和材质关系仍需要可信。优先减少风格强度，而非用另一组强参数抵消。
- **主体明确 vs 环境叙事**：收紧构图可增大主体，也可能失去地点和尺度。先比较保留原构图、轻裁两个方向。
- **浓彩 vs 层次**：保住主辅色面积和亮暗关系；所有颜色一起增艳会削弱主色。
- **干净 vs 生命感**：皮肤、毛发和夜景颗粒中可能有有效信息；干净不是把纹理抹掉。
- **统一系列 vs 单张优秀**：先确定一张锚点，再做逐张匹配；相同参数并不产生相同观感。

## 参考图与大师灵感

有用户参考图时，实际看参考图，拆成可迁移的关系：黑白端点、明暗分布、主辅色、肤色、光源、颗粒与构图。不要声称精确复刻未知 LUT、相机曲线或曝光。

风格中由拍摄产生的部分——镜头距离、景深、时机、天气、场景布置、长曝光、光源——通常不能由调色补齐。明确哪些可以通过已有像素改善，哪些适合下次拍摄练习。

## 保留与停止

没有明确改善空间时，可以只保存 `review`，不创建候选。已出现肤色失真、光晕、色带或蒙版边缘时，先撤掉造成问题的处理；不要继续加参数掩盖。达到意图且没有可见副作用就停止，不为测光分、个人默认风格或“高级感”继续补偿。
