# 文字点缀

## 何时进入文字模式

用户明确要求照片加字、可爱短句、贴纸标题、日期或图文封面时，进入独立 `lettering` 模式。普通审片、提亮、调色、大师风格和组图统一不自动加字；也不从性别、人物外貌或历史浏览推断用户喜欢可爱装饰。

先保留修好的照片，再给文字候选。用户提供的文字准确照用；只改换行和排版，不擅改名字、日期、数字。没有文案时，可以给一个贴近表达的短句候选，让用户在预览中决定；不编造照片里的地点、关系或经历。用户只说“更可爱”但没表达加字意愿时，先说明文字是一种可选方向。

## 看画面再排版

实际看当前成片，找低细节、亮度相对稳定的留白；避开眼睛、脸、动物目光、产品名称与关键叙事元素。纯文字适合稳定背景；杂乱背景优先小面积贴纸底色，而不是加很重的描边。不要为了容纳文字重新裁掉主体。

常用起点是画幅边缘留 5%～8%，字号为短边的 3%～5%，短句不超过两三行；这些只是候选起点，须按画面与观看尺寸判断。手机查看时读得清，比桌面放大后的漂亮更重要。贴纸同样不能遮住用户在意的细节。工具只能检查范围越界，不能判断哪块留白适合放字。

主文案与小注释需要层级；颜色和字形各选择少量变化。可用 1 处主文字，必要时再加小日期。爱心或星光只在用户期望这类气质时使用，不把四处文字额度填满。

## 风格与取舍

| 方向 | 适用条件 | 检查与回退 |
| --- | --- | --- |
| `airy` 留白短句 | 安静、轻松的画面；背景有干净留白 | 浅背景上奶白字容易消失，改深字或换位置；不通过加大字号压过主体 |
| `sticker` 奶油贴纸 | 日常、宠物、甜点；用户明确想要可爱点缀 | 默认奶油底和暖棕字，可以换浅粉底；底色占比过大时缩短句子、缩窄范围，或去掉装饰 |
| `editorial` 小标题 | 旅行叙事、作品封面、小标题 | 标题会先于照片吸引注意，纪实和情绪特写应保持克制；中文衬线与拉丁衬线实际字体可能不同 |

字体来自本机。先运行 `lettering` 查看真实字体；不同机器不保证完全相同字形。中文字体缺失会明确报错，不把方框当成成功成片。文字样式独立于照片风格层，不能代替修片。极长文案更适合图文页面，照片上可只保留一句。

## 候选与精调

使用 [工具参考](tools.md) 的文字点缀结构。`textOverlays` 是整个文字层数组的绝对替换；修改一处时保留其他处，空数组表示明确移除。坐标相对最终裁剪画幅，字号相对短边，因此应先稳定构图再排字。图幅变化后重新查看实际排版。

1. `inspect` 读取当前已接受版本、意图、文字层和最新批注。
2. 用 `lettering --input` 创建候选，仅改变文字；填写当前 `revision`、`baseVersion` 和 `mode: lettering`。
3. 看真实文字预览，检查字形、换行、可读性、主次和遮挡。需要时检查局部预览，并修正位置、宽度、字号、倾斜和配色。越界会报具体原因，不静默截断文字。
4. 在本地预览的「文字点缀」中，用户可手改文字、选择样式、切换文字层和微调，再生成试片。接受、取消与恢复沿用版本流程。

候选创建和预览失败时当前修片版保持原样。文字能力没有额外模型服务；判断、文案与讨论由宿主 Agent 完成。

## 成片与偏好

`preview --without-text true` 和 `export --without-text true` 只在该次输出隐藏文字，不改变项目或光色。交付时按用户用途提供有字或无字成片；需要两份时分别导出，不覆盖已有文件。

预览与导出使用同一份布局，位置、字号、贴纸圆角和装饰随画幅缩放。导出后查看真实文件，尤其是小图中文笔画和 JPEG 边缘。

文字候选接受记录带 `mode: lettering`。可记录用户接受了什么排版、配色与句子，但不能将一次可爱贴纸的选择当作曝光、肤色或长期摄影口味的偏好。
