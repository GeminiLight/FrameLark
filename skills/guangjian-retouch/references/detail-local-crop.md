# 细节、局部范围、构图与输出

## 细节检查

先适应窗口判断观看顺序，再在接近源分辨率的位置检查。优先眼睛/头发、肤色渐变、树枝/山脊、平滑天空、文字和局部范围边缘。截图被再次缩放时不能声称是在检查原片 100%。

| 现象 | 可能来源 | 处理与验证 |
| --- | --- | --- |
| 轮廓两侧有亮/暗线 | 锐化、清晰度、局部对比过强 | 减少对应处理，比较高反差边缘，不追加降噪掩盖 |
| 毛发像蜡、树叶黏连 | 降噪或纹理抑制过度 | 减少 denoise，保留可接受细颗粒；不能造出缺失细节 |
| 阴影显粗糙 | 原有噪点被提亮、过度锐化、压缩 | 先回退不必要的提亮/锐化，再适量降噪 |
| 天空有条带/块状 | 8 位量化、压缩或极端曲线/HSL | 减少极端映射，源图已存在时说明；加颗粒不是恢复原始过渡 |
| 全图柔软 | 失焦、运动模糊、缩小、镜头特性 | 先核对源图与预览尺寸；锐化能改善边缘观感，不能承诺重新对焦 |
| 细节在预览正常，成片过硬 | 尺寸、重采样、输出锐化与颗粒尺度差异 | 同位置同倍率复看实际导出，不能只看预览成功 |

Adobe 建议在 100% 视图观察锐化和噪点，并区分亮度与颜色噪声；见 [官方说明](https://helpx.adobe.com/ca/camera-raw/desktop/using/sharpening-noise-reduction-camera-raw.html)。本地引擎没有分别暴露 Lightroom 的半径、遮罩或色噪点滑块，不能把操作说明冒充可用工具。

当前细节处理在全局调性之前执行；局部处理在全局之后。粒子和高频纹理在缩放后会不同，输出检查应说明尺寸。grain 是气氛选择，不用于假装细节；已有噪点的照片不必再加颗粒。

## 局部选择与真实边界

先判断问题是否确实只影响一处。如果需要多个重叠大范围补偿，先检查全局方向是否错了。

- rectangle：适合规则区域，边缘羽化后仍可能覆盖背景。避免直接贴脸形成矩形亮斑。
- radial：适合脸、人物或光斑的大致区域。当前羽化发生在椭圆边界**以内**，不会把范围扩散到框外；主体靠边时需要扩大框并再检查。
- linear：适合天空到前景、画面一端到另一端的渐变。当前 start→end 是从高权重到低权重，作用可延伸到**整个画面**；批注框不是渐变裁切边界。框住小物体不代表渐变只作用小物体。
- 当前没有语义人物/天空分割，也未在本地工具开放画笔。不能写“精准选择脸部”或假装已有选区边缘检测。
- 局部按顺序作用于已处理的像素；重叠部分可能重复改变亮度和颜色。两个局部不是互相隔离的 RAW 曝光层。检查交界、天空、背景和原来未提及的位置。
- 使用 enabled:false 分别观察作用；建议解释目标、范围、主要变化和代价。删除讨论批注不等于撤销历史局部调整。

## 裁剪与拉直

裁剪改变的是叙事和信息，不是单纯“去掉杂物”。先列保护元素：人物肢体、视线方向、光源、动作去向、建筑结构、倒影、前景落脚点和具有意义的背景。

1. 把保留原构图作为候选之一。只有边缘干扰显著时再试轻裁剪。
2. 说明删掉什么、留下什么，以及主体在画面中的新关系。留白、斜线和偏心可能是成立的表达。
3. 目标比例由用途决定。横版风景不自动改竖版；竖版传播也不应切掉关系主体。
4. 拉直先找可信水平/垂直参照。坡面、透视线和镜头倾斜不能一概当作地平线。当前只支持旋转与裁剪，无镜头矫正、透视重建、生成扩展。
5. 比较完整原片判断叙事，再使用共同裁剪对照判断光色。compare 的共同范围本身不足以证明裁剪安全。
6. 归一化坐标相对正向原片；比例计算同时考虑源图像素长宽。不要误以为 crop.width / crop.height 就是最终画幅比。

工具会拒绝切到受保护标记。只有用户明确授权才用 allowProtectedCrop；不得删除保护标记绕过限制。

## 导出与交付

先问/推断用途，再选尺寸；已经明确用途不重复问。share 适合普通屏幕分享，print 仅提供较高质量和 ppi 元数据，不等于已经做印刷软打样。当前工具无 ICC 自定义/CMYK/显示器校准/打印机纸张模拟。

工具输入是正向 8 位 sRGB 工作图，不是无损 RAW 显影；JPEG 再编码有损。PNG 能避免新的有损压缩，但无法恢复之前丢失的信息。检查源尺寸、裁剪后尺寸、导出实际尺寸和编码结果；当前最大 8192 px / 1600 万像素且不放大，不承诺每张都能原尺寸输出。

高频细节在同尺寸 PNG 检查、不同尺寸重采样检查和 JPEG 编码检查是三个不同结论。至少复看最终文件的整体、主体和一处高反差/平滑区域，再交付。
