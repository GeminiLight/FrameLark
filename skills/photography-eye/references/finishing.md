# 后期成片：从拍摄意图到光色与质感

适用：完整五选项图板、用户要精修后的样子、拍完怎么调色、复拍后的处理。T24–T26的[官方资料](sources.md)支持控件事实；下面的现场衔接和后期卡为本Skill综合设计，不是现成滤镜或经验证的万能配方。

## 拍完怎么调色精修：拍摄与后期的分工
<!-- knowledge-id: finishing#1 -->

用户问拍完怎么调色精修时，先说清哪些效果靠拍摄得到，哪些靠后期完成。拍摄安排现场的形状、空间与时间，后期组织已有信息的明暗、颜色与材质；两者共同指向成片目标。

每张先描述成片里的关系：谁亮谁暗、哪种颜色主导、哪里有温度、什么材料柔软或有重量。颜色、局部光影和材质是摄影表达的一部分，不能把全部成片能力缩成裁剪，也不能用一句“后期加滤镜”结束。

同时写两栏意图：

- **拍摄负责**：机位和遮挡、动作与间隙、主体大小、对焦、运动模糊、真实光向、实际景深。前期应捕捉所需细节，能用RAW时可保留RAW＋JPEG；RAW并不保证所有高光都能救回。
- **后期负责**：在已有信息上安排曝光与调性、白平衡与色彩关系、局部明暗和材质处理、拉直/有限构图整理与输出。背景变暗和背景消失不同，局部明暗不等于重新造光。

生成参考先区分同视点精修目标和新机位条件概念。缺失的云纹、失焦眼睛、花瓣纹理、陌生人的脸或新的光源不能作为精修成果。机会靠新视点才成立时，后期卡只能在用户拍回后适配。

## 调色与精修的决策顺序
<!-- knowledge-id: finishing#2 -->

围绕照片目标执行，某项无需改变就明确保留，不强制每张都推全部滑块。

1. **文件和基准**：实际读取照片，确认RAW/已处理JPEG与现有风格。保留原片；在固定基础上试调整，避免把机内色与滤镜反复叠加。软件未知先给方向，具体数值注明软件/控件与基准。
2. **白平衡**：比较白瓷、灰墙、肤色等多个线索与现场色光。需要暖意时可以保留暖高光，白物仍可信；不能把米色材料强拉纯白。JPEG的相对温度和RAW的Kelvin不是一套数值。
3. **调性**：先重要亮部和中间调，再暗部重量与曲线；阴影可能是构图主体。按试片决定曝光方向，不统一“高光-100、阴影+100”。已剪切信息不称恢复。
4. **色彩组织**：明确主色与干扰色，按需要选Hue/Saturation/Luminance或颜色范围，而非全局加艳。颜色范围会影响同色衣服、皮肤、植物或包装，范围不等于对象；目标只在某处时加空间约束。
5. **局部明暗**：在明确位置轻提/压已有信息，检查羽化、溢出和轮廓光晕。脸不必更白；背景不必更黑。局部收益应是让动作、体积或形状更好读。
6. **质感与输出**：按材质分配纹理、锐化和降噪。纸巾、皮肤不应像金属；平滑天空不应充满清晰度。看分享尺寸的吸引力，再看接近源分辨率的副作用，实际导出再复核。

可选择明显而有意的风格化调色，例如浓郁、柔和、冷暖分离或黑白；应说清具体颜色和调性代价，不把“必须自然”“强度小”当审美标准。强风格也不能伪造主体、天气或原有细节。

第一步也必须由当前图的症状支持。不能看见餐盘就默认降色温、看见绿植就默认去绿：先指出哪块白盘偏蓝/黄、哪些绿层混在一起，再给调整方向。线索不同或原色已合适时先保留；试改后比较多处材料，不能为了给一条配方把白盘改得更蓝、把青绿围网改成品红。明显失焦或运动软化的输入，优先建议确认对焦后复拍或更宽取景，调色与生成不能替代捕捉细节。

## 每张照片的后期卡
<!-- knowledge-id: finishing#3 -->

图上写一行“后期：红布微暗｜黄巾柔暖｜保留硬影”，图外逐张给：

开头先列**一项优先调整＋成功标志**，作为用户的第一步；其他操作只在对应问题出现时使用，共用软件/文件基准集中写一次。普通手机且软件未知时先给图库基础控件可做的方向，再将局部蒙版和具体数字放入明确的软件可选分支。没有局部工具就保留该处，不为追一个小主体改变整图。

| 内容 | 要回答的问题 |
| --- | --- |
| 成片目标 | 哪个主次、色彩或材质关系会比原色更好读？ |
| 整体光色 | 白平衡、曝光、高光/暗部与曲线哪些要动，哪些保留？ |
| 分色调整 | 具体什么颜色，向何种Hue/Saturation/Luminance变化，影响哪些别的物体？ |
| 局部精修 | 画面位置、选择范围、操作、强度起点和羽化检查；没有收益可以不做 |
| 材质/收尾 | 哪里需要纹理/锐化/降噪，哪里保持柔和平滑；输出边缘检查 |
| 检查与回退 | 成功标志、过头征兆，以及先撤哪一项 |

需要数字时只给少数相关控件的**试调起点或区间**，标明软件与基准，未实际执行不能写成“已验证配方”。相机f值/ISO、后期曝光EV、JPEG色温滑块、色相角度分别标单位。不同软件和本地修片引擎不可直接抄值；查它实际支持的控件。图板不必塞下全部滑块，完整文字独立可用。

多个候选可以共用调色骨架，逐张适配材质和局部；不把同一构图换五套滤镜算成五种拍法。用户仅追问调色时保留原P编号和构图，直接展开那一张后期卡。

## 把题材关系变成具体动作
<!-- knowledge-id: finishing#4 -->

| 可见关系与目标 | 可尝试的处理 | 检查与反例 |
| --- | --- | --- |
| 红衣对灰色街道，动作是主角 | 保留红衣分量，按试片收干扰绿/砖色；局部轻提必要的手臂或脸部中间调 | 黑衣仍有重量，肤色深浅不改；全局橙色影响砖墙和皮肤，先查范围 |
| 黄纸巾、红布、白瓷与金属 | 黄巾保留暖色；先用空间蒙版选布面再适度降低饱和或曝光，避免全局红色HSL同时改变红包装；整理白瓷高光与已有投影，金属亮边不压灰 | 检查蒙版是否越到包装、白碗/巾边；HSL明度值不能直接搬到蒙版曝光EV。保留硬光与盘影，白瓷不能全染黄，金属不能像塑料 |
| 粉花与绿叶 | 花色保持渐变；若叶色争抢注意，轻收绿色饱和或局部亮度；花瓣局部少量纹理 | 花瓣不出现色彩溢出，叶不偏成假青；不要把源图未见叶脉当锐化结果 |
| 灰云、绿带、小木椅 | 保留灰天的温差与层次，按需要收亮草；木色留作小落点 | 去雾不把云变暴风，树冠边缘无光晕；小人只按真实分辨率，不生成人脸 |

这些是依可见关系的处理假设，默认先试一个方向。黑白若抹掉原来有价值的红衣/花色，需要说明舍弃并比较，不把它当专业捷径。

## 成片参考、实际执行与验收
<!-- knowledge-id: finishing#5 -->

完整图板默认展示有后期意图的最终照片参考，同时保留逐格的拍摄说明与后期卡。每例一次整板生成，原片框示可以单独作为代码图示；无需为每格各生成一张未调色和一张已调色照片。仅要求原色或边界时沿用用户要求。

生成说明不能只写“精修、高级、胶片”：逐格写实际调性、主辅色、局部位置和材料。标“AI拍摄＋精修目标，非实拍修图”。若生成图改变了折纸、肤色、云形、器皿文字或景深，那一部分不进入可执行后期卡。

实际修图有工具且用户已要求时，沿用授权继续。项目可读 `guangjian-retouch` 的光色/正向精修/工具参考，交接原片、P编号、目标、具体步骤、禁止改动和未验证条件。摄影眼知识本身可独立使用，不把安装修片Skill作为问拍法的前置条件。生成工具和实际像素工具遵循宿主规则，不为制作示例另建收费服务。

验收分别记录：拍摄关系是否成立、原色到修色的同构图收益、材料/边缘副作用、图文和参数一致、源图内容保真。构图和颜色同时变时不能宣称提升全来自调色。没有真正处理原片时记“后期计划＋生成参考”，不能声称已经精修了实际照片。
