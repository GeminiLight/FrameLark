## 如何使用证据

- **设备原始说明**：确认具体型号的功能与限制；不能外推到所有相机。
- **原创摄影教学**：作者公开的技术解释或亲自讲述的实践。区分光学事实、经验起点和审美偏好。
- **创作者方法**：可作为观察和练习的启发，不能升级成普适审美真值或保证效果。
- **作品/联系表/出版介绍**：证明有这种实践和作品，不证明任何构图模板有普遍优势。
- **本 Skill 综合设计**：现场动作卡、候选编号、复拍检查点和练习；不是下列作者共同发布的方法。

参数区间、机位高度和距离默认是可检验的经验起点。新结论需要具体现场条件和反例。论坛、搬运、AI总结、营销标题仅用于发现线索；重要技术说法回到原始文档核实。

## 冲突与未知

1. 简化教学有时把“焦段”与“透视”连说，实际拍摄还伴随视点改变。现场指导明确分开走位和取景范围。
2. 官方教程也含审美经验与品牌背景；“简洁”“居中”“强对比”“浅景深”只有条件性作用。
3. 没有来源能替一张普通勘景图测出可靠精确距离或保证云色变化。用试拍与屏幕关系检验。
4. 本轮资料建立决策基础，未证明这个 Skill 能达到所有题材的专业摄影水平。持续验证来自真实用户复拍与独立摄影评价，而非模型自评分。
