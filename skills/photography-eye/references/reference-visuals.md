# 参考画面：让用户看见方向，也找得到现场

适用：附现场图问“咋拍／这里怎么拍”的默认图文交付，以及候选参考、完整勘景和明确生成画面的请求。视觉工具遵循宿主能力与用户授权；不需要新模型 Key，不默认额外外部服务。

## 按真实覆盖范围选形式
<!-- knowledge-id: reference-visuals#1 -->

| 形式 | 能说明什么 | 标注 |
| --- | --- | --- |
| 在原片上画取景框、关系线/目标区域 | 当前视点里的选取与视觉关系 | 原片取景示意 |
| 从原片已有范围裁取不同画面 | 同一视点/时刻的边界选择 | 原片裁剪参考；不是新机位实拍 |
| 简图或俯视走位图 | 已知地标之间的操作与方向 | 走位示意；未知通路不画成确定路线 |
| 基于现场输入生成候选成片 | 表达和新视点的概念方向 | AI 拍法示意，非实拍；新机位需现场验证 |
| 有明确调色/局部意图的生成成片目标 | 拍摄完成并精修后的光色和材质方向 | AI拍摄＋精修目标，非实拍修图 |
| 实际处理原片像素得到的照片 | 所用工具真实执行的裁取、调色和局部结果 | 原片实际修图；保留原片与修改记录 |

原片框示最适合精确教边界；草丛前后遮挡或新机位透视不能靠裁剪模拟。不得声称缩小裁剪框就等于精确的 50mm 视角；未知原图焦段、画幅或数字裁切时更不能换算。

需要准确显示原片范围时，用宿主图片视图、取景框或保留源图的图示界面。生成工具即便被要求“只裁剪”，也可能重画窗格、云和石板；生成结果仍标 AI 示意，不冒充确定性的原片裁剪。无法保留结构时退回原片框示，以原图里的框和对应范围说明拍法。

首次附图问怎么拍的默认形式就是参考板加逐张文字：先给一句立即主推，再在当前工具支持图片输入与生图时直接生成参考板，不等用户追加生成要求。先通过可调用工具及其说明检查能力，不用生图探测。工具不可用或用户只要文字时，用可执行拍法与原片框示／简图交付；不能把未生成的图片称为成品。光线正在变化时先拍，参考图不成为等待条件。只追问一个动作时不重复生成整板。

完整参考照片默认呈现 [后期成片](finishing.md) 设计的调色与精修目标，每张图外有后期卡。原片框仍保留原色，用来解释取景；原色框与最终参考的差别须分开指出机位、构图与光色贡献。实际执行的修图另标，不把AI参考当已处理的原片。

## 主推大图、候选小图与整板生成
<!-- knowledge-id: reference-visuals#2 -->

文字方案、图卡、追问共用 P1–P5 编号和具体名字。完整图板默认五个选项：一张主推和四张候选；沿用用户偏好，机会不足不虚构。先按观看判断淘汰弱方案，再设计版式，不能让五格排版反过来决定拍什么。

### 一次生成整板

生成说明中把每个面板的最终短文案单独列为需逐字保留的文本，不只传长段方案让生图模型自行概括。例如「P3 局部｜45°斜俯｜55mm f/8｜检查1/160s或更快｜自动ISO｜局部裁切示意」。新角度或需要裁切的放大结果，在该格或图外明确说明。实际评估发现只有标题与参数列表时，模型可能省略角度；省略仍记缺项，详细文字补齐不等于图内已写。

默认每轮完整勘景用**一次生图调用、输出一张完整参考板**。主推图、全部候选、标题、机位/角度提示和参数在同一请求中完成。多个现场原片与排版参考可以作为同一次调用的输入，明确各自角色与方案来源；输入多张图不等于分别生成多张成片。

先整理每个方案的完整文字，检查源图、器材范围、参数、取景边界与编号，再把全部内容写入一个生成说明。不要先逐张生成主图/候选再拼装，也不要默认出多版挑选，以减少调用和等待。

当前原片框的比例用实际源图像素计算：`宽高比 = 框宽 × 源图宽 / (框高 × 源图高)`。在生成说明里逐格写横竖幅和这个比例，按照片比例安排版式；混合横竖图时为竖幅留位，不能为了两列网格把它改成横幅或拉伸。没有选定原片框时，只写方案需要的画幅，不编精确比例。数值与提示能帮助约束，不保证生图工具遵守。

排版参考的照片格可能接近方形，不把四个候选一律定为3:2再要求填满。生成前一起检查版心、照片比例和关系：能保住主体才调整选框；否则缩短信息区或留边，不能让参考版式悄悄改变四边。输出只保持“横图”而实际比例变化，仍记框执行偏差。

生成后仍实际检查。参数错误、关键场景关系偏移、文字无法辨认或图文冲突需要处理：能用文字/原片框示讲清就补充，确需修改图片时优先一次针对原板的编辑，并说明增加了一次调用。小幅审美微调不触发自动连续出图；用户明确要求新版本或更多板时再按其需求制作。不把“单次整板生成”说成整段对话总共只调用过一次。

### 本项目默认版式

沿用本项目用户最新选定的图册层级：**左側通高大照片约占半板，右側白底四候选2×2；主图短标题叠在照片的安静处，候选标题与紧凑参数在照片下方。** 参考图的排版与内容分别判断；不照抄参考里的器材、日落、人物或建筑。

- 主推图约占整板四至六成，优先左側整幅铺到边缘；用最有说服力的关系作大图。叠字用真实天空、暗墙或平静背景，不能为了文案造留白或压住脸/动作/纹理。画幅或语义确实不适合时再改主图在上，避免为了版式切掉关系。
- 默认四个备选放在右側规整2×2网格，照片约占各格四分之三可作起点；照片之间留窄白缝，信息区紧凑。右側标题“另外四种拍法”以黑色衬线字为主，不加巨大的整板通栏标题。可留一条短的共用光色方向/拍摄检查，避免大提示卡、宽参数底栏和密集说明挤压照片。
- 每格有编号/名称、一句角度或机位、短参数。相机分支标焦段及基准、光圈/模式、快门策略和ISO策略；手机分支标实际可用视角、对焦与曝光操作。
- 图中参数也必须可行。`M+自动ISO · 24mm · f/5.6 · 1/250s`是一个条件起点；`A · f/5.6 · 自动ISO · 查看实际快门`不能被排版改成三个都已锁定的曝光量。未知量以“自动/查看实际值”表达。
- 图内信息简短清楚，字号在正常查看时可辨认；编号名称、角度与参数形成层级，后期可按照片空间用短句或集中写共用色彩方向。不要硬塞四行长卡到每格。详细走位、高度、俯仰、画面边界、对焦、时机、调色和失败回退放图外。交付前核对图内参数与对应文字。
- 成片本身要有主体关系、层次与清楚取舍，也要设计适合这张照片的明暗、配色和质感。等待方案可以呈现预先声明的另一光线；必须写出现条件。不能无条件加太阳、补楼或删除关键物体使照片“变好看”。

一张参考板可以混合当前边界和概念视点，但每格标清类型。主体来自哪张现场输入必须对应；不把不同地点的楼、河和树拼成可达的新机位。

## 用照片呈现选择
<!-- knowledge-id: reference-visuals#6 -->

照片占主要面积，主推有足够大小，四个候选的照片不能缩成无法比较的小条。可用主图在上、候选两行，或根据横竖幅调整；避免巨大的标题、说明栏挤压照片。标题简短，逐格保留编号、机位类型、角度和参数；长解释放图外。照片自身应呈现选取的手势、形态、色彩或尺度关系，而不是靠「高级」文案制造效果。

生成说明逐格写「视觉抓手、拍摄动作及其效果、保留/排除、画幅、背景关系、成立条件、风格与禁止新增」。当前框对应原片；换位图写试拍方向、高度和屏幕目标，不编原片坐标。参考图可以表现真实重新对焦后的景深、已声明条件下的光影，以及鲜明的黑白、冷暖或色彩表达。分别说明拍摄与后期的贡献，不能把换天气、换主体或凭空细节说成修色收益。风格要落实到色彩主次、亮暗组织与材质，而不是只加「电影感」修饰词。

## 生成前锁定现场
<!-- knowledge-id: reference-visuals#3 -->

手机JPEG可能带旋转信息。先确认实际显示方向，记录存储尺寸与显示尺寸；框坐标、宽高比和界面覆盖框统一用显示坐标，不把原始横图尺寸套在自动旋转后的竖图上。保留原文件，实际查看界面里的框与对象是否对齐。小局部另记剩余像素；裁得合法但读不出细节时退回较宽关系。

记录可见的主体身份/数量、形状、位置关系、地平线、道路/水面走向、光源/阴影和真实天气。新视点保留已知物体与空间关系，允许动作导致透视、尺度和遮挡变化。未知背景不补具体新建筑或道具；若它决定方案能否成立，给现场观察条件与退法，必要时再请用户补该方向。不要求每次换角度先上传第二张。

使用宿主可用的图片生成/编辑工具。已有本地图片先实际查看，再按工具规范传入路径或最近图像；不得假称读取不存在的附件。照片只作为用户授权任务的输入，生成示例和私人原片默认不打包进公共 Skill。

按方案类型锁定变化：当前裁取保留原视点、光线和原片范围；新机位保留物体身份与已知空间关系，允许动作造成的投影、尺度、遮挡和真实景深变化；等待方案允许已声明条件造成的光影变化；可控灯光或摆放方案写清用户要做什么。不能把未发生的条件冒充当前事实。桥、花海、新人物等没有现场依据的元素不新增。物体出画要有取景或移动的原因，不能凭空消除后称现场可复刻。

```text
制作一张现场拍摄辅导的候选参考板。
一次生成完整参考板，主图、全部候选、标题、机位与参数统一排版；最终输出一张图。
输入图的角色：真实场景依据，不是待任意改造的素材。
若另有排版参考：只采用布局与信息层级，不借用其中的现场、光线、设备参数或物体。
已观察到的现场：<列出可见主体、空间、光线；未知项单独写>。
候选方案：
P1 <名称>：主推大图，<画幅、边界、主体关系；当前视点或条件新机位>；图内<机位/角度短句>、<自洽拍摄参数>、<后期短句>。
P2 <名称>：<真正不同的表达>；图内<机位/角度短句>、<自洽参数起点>。
P3 <名称>：<真正不同的表达>；图内<机位/角度短句>、<自洽参数起点>。
P4 <名称>：<真正不同的表达及成立条件>；图内<机位/角度短句>、<自洽参数起点>。
P5 <名称>：<真正不同的表达及成立条件>；图内<机位/角度短句>、<自洽参数起点>。
严格保留：<主体身份、具体建筑结构、已知场景关系>。
每格允许的拍摄变化及前提：<移动/高度/焦点/等待光线/可控灯光；若当前裁取则固定原视点与原光线>。
每张精修目标：<白平衡与调性、主色/辅色、具体局部明暗、材料质感及不动的部分>；不要仅写套滤镜。
不新增：<本场景容易被模型虚构的元素>。
不把取景排除解释为对象被消除；不补具体未知物体。新角度的合理投影可以作为待试目标，不声称精确复建。
图片文字包含编号、名称、短机位/角度、参数起点；标“AI拍法示意，非实拍”。
含后期目标时标“AI拍摄＋精修目标，非实拍修图”；拍摄参数与后期操作分开写。
新视点仅为条件概念，不能呈现为精确测量或可达性证明。

```

这是内容说明，不是某个 API 的参数 schema。宿主工具如何编辑、传图、保存以其规范为准。

## 生成后检查
<!-- knowledge-id: reference-visuals#5 -->

生成的光照、景深和焦外形态不是相机物理模拟证据；图上f值/快门只是拍法起点，不能证明现场按这些值必定拍出相同效果。输入拍法若未实际看图、编造条件或超器材边界，先记录失败并修正文字，不能让漂亮生成图掩盖错误。

实际看输出，按生成前声明的类型检查：当前裁取是否保持原视点/光线/范围；新机位的尺度、遮挡和透视变化是否由动作解释，物体身份与路线是否仍成立；等待光线是否体现已声明条件。检查是否无原因地新增/删除物体，P编号、名称、角度和参数是否与文字对应。再看主图是否好看、每个候选是否真的不同、图内参数是否清楚可读。

新机位允许投影变化和重新拍清的细节，但纸面不能换语言、设备不能换类型；隐藏侧面无法对应时记「未确认」，不一律判失败，也不称准确复建。分别检查角度效果与该方案自己的四边：新视点合法不代表完整盘缘、留白或焦点要求已经兑现。

检查重点由表达反推，生成前列两至四个身份或空间锚点，以及允许改变的投影/光影。当前裁取可核对窗格、影子、云边等原片细节；新机位核对主体身份、已知关系及动作因果，不要求原投影不变。短文案正确或总体相似不证明关键关系保留。重新靠近、对焦可能获得更多真实细节，但生成的清晰目标只是复拍设想，不算原片细节找回。

有原片框的方案先检查对象确实入框，尤其细笔、灯底、盘缘和局部水印边界；不要只算坐标。新机位用移动、高度、俯仰和屏幕关系检查，不套原片框。若计划自身矛盾，分别记录计划错误和生成偏差，保存初始方案后修正交付文字，不重写首次提示抹掉错误。更宽建筑围合、完整饼尖或清楚叶脉须判断是否来自预先声明的复拍机会，未知部分仍待验证。

后期目标另看：色彩是否有主次、重要亮暗有层次、材质是否可信、是否改变肤色深浅或过度压灰；图内后期短句与图外步骤是否对应。生成出的新光、纹理、焦外或被抹去的物体不能写成调色滑块的成果。画面同时换机位和调色时分别标贡献，不声称是同构图修色对照。

单独看每格照片的真实边界和横竖方向，不能用图中文字“竖拍”当方向证据。排版即使清楚漂亮，若保留了本应出画的杆子、收少天空的动作未落实，或竖框变横图，仍记录该编号失败。把“文字拍法可执行”和“生成画面忠于该拍法”分别判断。需要补充时让用户同时看到原图框、该编号的正确动作与生成格的具体偏差；框示不另算生成成片，也不抹去首次出图失败。

没有动作依据的结构偏移不能交付为忠于现场的参考。能小范围修正就修正；否则当前裁取退回原片框，新机位用动作卡或走位简图说明，并指出概念格的具体偏差。生成参考不是光学模拟或参数预测，也不能证明用户必定拍得出同样效果。

退回时沿用原编号与正确拍法，在偏移那一格或图板旁给具体说明；当前裁取用原图框，新机位用动作与屏幕关系，等待用出现条件作操作依据。仅在页尾写“AI生成”不够。首次板保留作表达示意与失败记录，不能继续称偏移格准确，也不在看到失败后才改称“换机位”。审美、文字操作和现场成立分别报告。

例如草带仍向右延伸，但石板变大、间距重排、透视变陡：表达方向相近不代表当前视点忠实。不能只看“没有加第二栋楼”就通过。检查应覆盖方案最依赖的细节，而不是要求所有微小像素完全相同。

保存供项目使用的图时写入项目的案例输出目录，提供绝对路径/可打开文件；仅临时讨论的预览按宿主规定处理。保留提示与检查结果便于追踪，但不把私人原片嵌入可分发知识库。
