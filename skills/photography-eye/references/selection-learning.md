# 选片与练习：把这次选择变成下一次的眼力

适用：用户带回复拍、问哪张好、希望系统练习。作者和联系表启发见 C01–C06/T17/T18 的 [来源](sources.md)，本页练习为综合设计。

## 对比选片
<!-- knowledge-id: selection-learning#1 -->

实际看完整图，再用一致观看条件比较。输入只有一张就不冒充已看过连拍；缩图用于关系，源图细节用于焦点和运动。对比裁剪不同的照片时先各看全画面，不用共同裁剪悄悄藏掉差异。

围绕同一目标比较：

- 关系：动作、视线、轮廓、间隙、环境证据。
- 时机：哪个瞬间让关系更完整；只用可见动作解释。
- 组织：边界、层次、重心、形与色的呼应。
- 技术：关键位置是否清楚，重要亮暗是否可读，缺陷是否真正影响表达。
- 代价：更干净是否少了故事、更紧是否失去尺度、更快快门是否丢了运动感。

输出「按当前目标选 A，因为这里的可见差别；B 在另一个表达目标下也成立」。允许难分高下或原版更好；不从参数高低推断审美优劣，不统一按锐度和饱和度排名。

组图额外看信息互补、重复、开场/连接/结尾与节奏。一张独立不抢眼的环境图可能有连接作用。排序要依据已看过的照片和用户想讲的内容，不为照片编造事件。

## 一次练习只验证一个假设
<!-- knowledge-id: selection-learning#2 -->

| 这次遇到的问题 | 练习 | 回来看什么 |
| --- | --- | --- |
| 背景轮廓粘连 | 固定焦段，当前位与侧移位各一张 | 分离是否更清楚，环境有没有损失 |
| 不知道低机位是否有效 | 同位置站立与半蹲各一张，不一起改焦段 | 前景变大后是否帮助关系、是否挡住主体 |
| 只会拍全景 | 在同场景找环境、关系、细节中的两种有效表达 | 信息是不是不同，而不是简单裁切 |
| 不会看光 | 固定主体，观察两个可达受光位置 | 阴影边界、轮廓、表情和材质的变化 |
| 构图模板太机械 | 同一关系比较居中与偏置，按目标选择 | 空间方向和感受，而不是规则是否满足 |
| 普通地点无从下手 | 在熟悉地点选一种变化或主题，保持观察 | 哪张有明确的选择理由 |
| 想拍瞬间 | 固定可见舞台，比较两次不同动作阶段 | 手势、脚步、间隙是否完整 |

有时间/运动窗口时先完成照片，练习可留到之后。用户只想得到拍法时不强迫其学习。

## 成长记录
<!-- knowledge-id: selection-learning#3 -->

用户希望记录时，保留照片/版本引用、现场条件、目标、选择理由、一次动作与结果，以及尚不确定的条件。结论分清「工具事实」「本案例观察」「个人偏好假设」。

个人偏好来自明确选择及理由；同一次选片不证明其所有照片都喜欢长焦或冷色。当前意图优先。私人记录与公共案例分开，新增通用方法需多场景与反例支持。

学习成功看用户是否能说出关系和取舍，并在复拍中检验；不输出无依据的百分制“摄影眼成长值”，不把阅读量/练习次数当水平证明。
