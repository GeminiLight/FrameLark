# 共享修图方法验收 · 2026-10-08

固定协议见 [manifest.json](manifest.json)，汇总见 [results.json](results.json)。使用本机已登录的 ChatGPT Codex 订阅，指定 `gpt-6-astra`、`xhigh`，每项一次，单项上限 240 秒。没有调用付费 API，没有对失败场景重跑，也没有人工修补模型内容后计为通过。

输入是仓库的 640 × 427 SpaceX 公有领域夜景，SHA-256 在 manifest 中。每个 `*-request.json` 保存实际提示与 Schema，图片字段改为同目录文件名及字节哈希，可据此重建原请求。`*-raw.txt` 是原始完整回复；`*-validated.json` 和 `*-compiled.json` 为正常化与编译结果。运行时注入版本、策略来源与图像身份，不让模型编造这些字段。

| 场景 | 结果 | 证据边界 |
| --- | --- | --- |
| 结构化诊断 | 通过契约并保存 | 指出下沿云带与塔脚层次问题；不证明诊断唯一正确 |
| 整体提亮、保护已有亮部 | 通过契约、编译和像素约束 | 单项内曝光 +0.4 EV 加实时亮度蒙版；暗部平均增加 8.61 个 8 位显示级，368 个近白高光像素平均变化 0 |
| 原步骤 EV 再增加 0.25 | 超时，未通过 | 240 秒取消，未获得完整回复；不能声称此项语义已验证。确定性测试独立覆盖数量、ID、maskRef、opacity、后继与撤销 |
| 明暗、色彩、几何三项取舍 | 通过契约及逐项编译 | 三项独立可选，几何仍在固定阶段，无虚构硬依赖 |
| 缺少语义分割及外部图片编辑 | 通过 | 明确无法执行，返回 `none`，没有用近似范围冒充能力 |
| 同目标成片复审 | 通过审核协议，试片需返修 | 模型给出 `revise`，保留下沿暗部的 blocking 问题；Agent 交付确被拒绝，见 [审核门禁](audit-delivery-gate.json) |

五项通过是输入/输出契约及可观测行为的结论，不是五张成片通过审美审核。复审使用预先固定的试片，与提亮案例分开；原步骤修改也使用预先固定的含蒙版、70% 强度和独立后继的配方，避免因前一场景结果而更换后续输入。

实际查看了 [原片](night.png)、[提亮后](protected-lift-after.png) 与 [实际蒙版](protected-lift-mask.png)：天空、塔架及暗地面可读性增加，亮灯核心与火箭亮面被排除，未在当前尺度看见突兀光圈。光晕暗外围仍可能变化；这只是该步骤的亮度保护，不是永久像素锁，也不是语义分割。原尺寸导出、其他题材与审美泛化不由这个小矩阵证明。

[最终运行时重放](final-runtime-replay.json) 和 [资源依赖重放](dependency-replay.json) 使用同一原始回复，无新增模型调用。后续源数据绑定和依赖检查仍通过。运行器会保留未来超时场景中已经收到的部分回复；本次超时没有完整回复文件。
