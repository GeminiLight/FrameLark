## 已有证据

- 原基线 414/414；#16 之后的集成套件最近 473/473，随后整数 Schema 与取消渲染回归分别通过，最终完整套件待记录。
- 共享引擎 41 个模块逐字节一致，网页与独立 Skill 共用同一个 DOM 属性组件；架构边界检查通过。
- 文件迁移、源校验、保护引用、旧锁拒绝、交换往返、候选部分选择和预览图像校验由项目/像素测试覆盖。
- 实际浏览器：网页 EV 调整；刷新读取配方；70% 强度准确显示；撤销、重做、再次撤销；原生精修创建并接受实时亮度高光蒙版；真实 Codex `gpt-6.1-sol` 用原步骤 ID 提出 EV 0.25，保留蒙版与 70% 强度，网页完整预览后接受并保存。
- 真实模型验收发现旧 Schema 校验器拒绝 integer，已修复并新增回归。模型提案只包含白名单命令；明确指定步骤时拒绝其他节点修改或反向补偿。
- 实际 IndexedDB：两个独立 writer；旧 writer 保存被 `STALE_DRAFT` 拒绝，新值保留，旧 writer 的未保存输入保留；旧 DB 版本打开被 `VersionError` 拒绝。
- Skill 安装到隔离临时目录，已运行独立 `document` 和 `document-tools`，并从独立 CLI 生成两项文档候选和真实 PNG。
- 渲染缓存每个网页 renderer 最多 64 MiB，以实际 RGBA、文档前缀和网格身份绑定。中间与末步修改、源/网格变化、结果副本、冷/热像素一致性由测试验证。最新预览取消真实终止旧 worker；不增加第二套 Node 渲染队列。
