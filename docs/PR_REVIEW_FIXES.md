# PR 审核修复 · 2026-10-04

本轮基于 Yijie Xu（@yeahjack）提交的 PR #3–#7，保留本机 Codex、流式对话、共享项目和以照片为主的流程，修复审核发现的保存、权限与交互问题。

## 修复范围

| 问题 | 处理 |
| --- | --- |
| 视觉请求可使用本机图片读取工具 | 禁用图片读取、终端、环境和其他无关工具；每轮明确空环境列表 |
| 启动超时或取消后仍接收旧任务回复 | 未知运行编号时关闭旧进程；已知运行编号时等待中断；旧进程消息不进入重试 |
| 对话保存改变局部层顺序或批注时间 | 按原合成顺序还原局部层；未变批注保留时间，无批注的局部层保留原字段 |
| 文件记录进入 HTML | 校验导出尺寸，在界面按文字转义显示 |
| 保存期间的外部更新被漏读 | 请求返回锁内提交的快照，处理积压通知；本地未保存编辑保留并显示冲突 |
| 网页版本迁移不完整 | 原子迁移当前编辑、命名版本和批注；重试有编号，等待期间的编辑与新版本继续保存 |
| 历史效果或保护在另存时丢失 | 拒绝网页不支持的历史转换；受支持批注保留保护、编号和时间 |
| 文件项目缺少命名与 A/B | 复用统一版本面板，支持命名、恢复及原片参与比较；保存不改变当前画面 |
| 恢复期间的新修改与旧保存响应 | 恢复时保留新修改并提示冲突，切换项目后忽略旧连接响应 |
| 文件项目草稿的原始字节 | 打开时保留原始文件 Blob，恢复后另存仍使用原片 |
| 定稿等待期间切换照片造成错绑 | 点击时捕获像素与偏好摘要，异步保存后仍归属原照片 |
| 顾问短屏幕内容覆盖输入区 | 统一阅读滚动区，固定输入区，收起空批注栏，调整小屏幕尺寸 |

- `npm run engine:check`：15 个共用模块一致；`npm run knowledge:check`：知识与参数结构检查通过。

- 检查 1280×577、390×844、320×720；对话区与输入区不重叠，手机无横向溢出。
- Codex 工具边界使用协议模拟和实际安装的 CLI 模型目录核对，未发送个人照片或调用付费模型推理。这些检查验证运行与交互行为，不代表模型修片审美已通过。
