# 照片编辑领域

- 原片：项目保存的输入字节与正向工作图；编辑不写回输入字节。
- 版本：已保存的完整编辑状态，具有稳定 ID。
- 候选：固定基础版本上的临时编辑，可比较、选择、接受或取消。
- 批注：用户讨论的画面范围；它与已保存的局部像素层分别保存。
- 工具操作：一个带版本的工具，接受目标与参数，并产生可重放的编辑效果或可复用目标。
- 工具方案：具有显式依赖的工具操作集合，选择变化从固定基础重新编译。
- 目标：整张照片、明确的区域或对象范围、批注，或另一工具输出的范围。
- 执行记录：已实际执行工具的版本、输入身份、进程或内联方式和预览身份；不替代审美审核。
- 视觉提案项：独立取舍的目标、预期收益、代价与诊断问题关联；可以包含多条原子命令。它不是像素步骤，也不是撤销事务。
- 像素步骤：稳定 ID 下的工具、参数、强度与版本化蒙版；裁剪旋转仍在固定几何阶段。
- 撤销事务：一次确认的编辑动作，可含多项提案或多条命令，不要求与视觉取舍一一对应。
- 当前审核：匹配源数据、画面状态、目标/批注、诊断及组合的最后一次复评。历史记录保留，匹配失败时不为当前画面背书；预览尺寸的结论不自动扩展到原尺寸导出。
- 方案来源与接受来源：模型生成、人手接受分别记录；人工接受当前有效候选可以不要求 ready，Agent reviewed 交付需要同组合有效审核。

候选事务、画面保护和审核规则属于项目模块。工具组合通过该模块保存候选与版本，不能自行绕过接受校验。细节见 [工具架构](PHOTO_TOOLS_ARCHITECTURE.md)。
