# 编辑步骤体验调整

基线：rebase 到最新 main `416bf42`，包含已合并的 #17–#23。范围为用户选中的五项：项目入口、保存位置、步骤操作、参数折叠、作用范围。文案沿用简洁、准确、克制的风格。

## 实施顺序

1. 顶栏统一“项目”，移除重复的“项目与记录”；明确项目与浏览器草稿的保存位置。项目中的版本、候选和导出记录继续可用。
2. 每一步提供可见的“更多”按钮；操作直接作用于该行，保留新基线的复制和依赖校验。常用参数优先，曲线与色彩混合默认折叠，收起时显示是否已调整。
3. “作用范围”显示基本选择、绘制与范围预览；参考画面、明度阈值及组合设置归入高级选项，明确只影响当前步骤。

## 视觉约束

沿用现有照片工作台的颜色变量：正文 `--ink #eceeea`、次要文字 `--muted #b5babc`、分隔线 `--line #414649`、面板 `--paper #292d30`、强调 `--accent #dfd2c1`。字体继续使用 `--font-ui`，控件与文字左对齐，不增设装饰卡片或新色彩。图片保留主要空间，操作区域依照实际调整顺序排列。

```text
照片与对比              编辑步骤：启用 / 名称 / 更多
                        步骤名称                重置效果
                        效果强度
                        基础参数
                        曲线 / 色彩混合（可展开，显示已调整）
                        作用范围与绘制工具
                        照片 / 范围预览
                        高级范围设置（可展开）
```

每行“更多”始终可见，触屏点击区域不小于 44px；展开后的操作占据面板正常布局，避免浮层被侧栏或移动端裁切。折叠状态在参数预览和保存期间保留，切换步骤时恢复该步骤的展开偏好。

## 验证要求

- 项目、草稿、失败与保存中状态准确；文件项目的版本和导出记录可访问。
- 对未选中的行执行操作也必须作用于目标行；暂停、复制、移动、删除、定向对话和撤销保持独立。
- 高级参数仍能编辑，收起后反映已调整状态；强度与重置不再被长参数列表推到底部。
- 高级范围仍支持实时/原图参考、组合与明度参数；范围预览不写入照片效果。
- 桌面与 390px / 320px 触屏布局无横向溢出，按钮可点击；网页与独立 Skill 检查器一致。
- 完成本地相关检查，并在最终提交上确认 CI。
