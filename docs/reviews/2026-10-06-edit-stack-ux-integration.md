| 问题 | 修复与验收 |
| --- | --- |
| 首次调整共享范围时，界面值改变但文件未保存 | 使用者数量不再触发属性区整体重建；共享开关单独更新。原基线保存 0.56，PR #24 仍保存 0.55；修复后网页和独立 Skill 均保存 0.56，另一步仍为 0.55 |

| 版本命名回车会触发后续默认按钮动作 | 回车与 Escape 消费当前文本输入事件；实际浏览器完成回车命名后继续 A/B 对照和恢复 |
