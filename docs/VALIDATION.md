# 已验证的内容与边界

## 技术检查

自动测试覆盖项目、文字排版、像素、会话、知识检索、逐项选择、参数/局部锁、区域保护、迁移、CLI/HTTP 一致性与 UI 竞态；另检查诊断、审核流程、来源重建、偏好档案和项目交换。运行 `npm test` 查看当前准确数量；新增测试均进入同一默认命令。部分技术检查使用生成图，交换检查使用公开照片；二者都不是自动审美质量证据。

关键像素断言包括硬核心逐字节一致、外带外等于新方案、透明 alpha 端点、旋转/裁剪网格、PNG 解码、准确细节裁片、参考损坏/丢失/循环、字体或管线不兼容拒绝、无字参考和恢复历史保护。UI 验证包括依赖联动、最新写入合并、revision/selectionHash、倒序图片、不可用旧预览下显式解除恢复，以及真实 HTTP 选择到接受闭环。

知识包含 114 个章节、14 款真实风格和 31 个真实参数；检查防止章节丢失及知识与引擎不一致。关键词检索没有视觉分类能力。

## 实际照片观察

此前由宿主实际看原片、候选与部分细节，完成暗人像、逆光山景人物和蓝调夜景案例。2026-10-02 另检查咖啡静物、猫与人工加噪夜景：

- 暖木桌与白瓷：保存保留依据，不机械校冷或裁剪。
- 猫：试日常柔光 20%，实际收益不明确，取消而保留原片。
- 夜景人工彩噪：比较 denoise 40 / 65，接受 40，保持曝光和锐化不变，复看 PNG；残余彩噪仍可见。

案例摘要、来源与取舍在 [案例手册](../skills/photo-retouch/references/casebook.md)。详细本地报告和照片项目没有进入仓库。小量低分辨率样片、编码变暗及人工噪声不足以证明所有真实肤色、RAW 或高 ISO 画质。

## 2026 年 10 月 2 日受控编辑验证

实际看过三种真实照片及对应输出：授权的高分辨率夜景塔楼 JPEG、NASA 宇航员人像、SpaceX 火箭地平线照片。后两张来自 scikit-image v0.25.2 示例数据；[官方数据说明](https://scikit-image.org/docs/stable/api/skimage.data) 记录人像和火箭照片为公共领域。个人照片与项目没有进入源码包或仓库。

- 夜景：933 × 1400 预览核心 128,968 像素、3265 × 4898 输出核心 1,579,858 像素，RGBA 不一致计数均为 0。检查完整图、塔楼/天空交界裁片与 JPEG 预览，没有在这次温和压力设置中看到硬接缝；原图低光噪点与亮光晕仍在。
- 人像：512 × 512，径向保护核心 28,493 像素，RGBA 不一致计数 0。实际看过发丝、肤色、领口邻近过渡；这只是低分辨率样片，不能推断所有肤色或高频发丝边缘质量。
- 天空地平线：640 × 427，矩形核心 71,040 像素，RGBA 不一致计数 0。天空轻调与地平线过渡在该样片上没有明显硬边；不能据此证明极端全局改色不会出现可见光色分界。

单次本机测量：塔楼参考/受保护 1400 预览约 0.25/1.44 秒；输出上限帧约 1.96/15.62 秒，后者进程 RSS 约 816 MiB。尺寸限制由原片与 1600 万像素上限共同决定。该数据不是跨机器基准、峰值内存保证或实时性能承诺。多个历史参考可能更慢，已限制引用深度和数量。

**未完成的验证：** 实际浏览器访问本机服务受环境策略阻止（ERR_BLOCKED_BY_CLIENT），未进行真实布局、鼠标拖拽、移动端、焦点与重连交互验收；没有以 HTTP 或状态测试冒充浏览器通过。
