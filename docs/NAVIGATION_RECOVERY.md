# 导航回退修复 · 2026-10-04

## 原因

PR #7 为突出照片对话，把学习、偏好和“我的”通过 `photo-first.css` 隐藏，并集中到“更多”。风格继续放在手动调整中，推荐与收藏默认折叠。这使原来的入口难以找到。功能没有删除，但使用路径发生了明显回退；上轮审核未拦住这项变化。

## 当前布局

| 位置 | 入口与用途 |
| --- | --- |
| 桌面左侧 | 图库、修片、学习、偏好 |
| 桌面左下角 | “我的”：个人档案、偏好与定稿记录；设置与帮助用小图标呈现 |
| 右侧 | 审片、精修、风格、顾问，宽度固定；快捷键 1–4 与顺序一致 |
| 风格面板 | 推荐与收藏直接可见，完整库、摄影师灵感、预览和强度沿用原功能 |
| 手机底部 | 图库、修片、学习、我的 |
| 手机顶部 | 齿轮打开工作台设置，触区 44 × 44 |

“我的”是现有个人档案入口，数据保存在当前浏览器；项目目前没有账号登录或跨设备账户同步。

## 代码与验证

- 风格使用独立的查看模式与面板，不再映射到手动调整；兼容原来跳转到建议和风格的动作。
- 修复主服务的请求边界：异常 URL 返回 400，不产生未处理异常；已发送响应头的失败只关闭该请求，不再次写入响应头。
- `npm test`：369 项通过；共用修图引擎 15 个模块一致。
- `npm run test:navigation`：真实浏览器验证学习、个人档案、偏好、四个面板、固定宽度、编辑参数与像素不变，覆盖桌面短屏、390 px 和 320 px 手机。检查已加入网页 CI。

导航检查需要 Node.js 20.9+、`agent-browser` 0.38.1 和它的浏览器运行时：

```sh
npm install --global agent-browser@0.38.1
agent-browser install --with-deps
npm run test:navigation
```

检查使用独立临时工作区和授权夜景样张，关闭模型接入，不读取个人草稿或请求模型推理。
