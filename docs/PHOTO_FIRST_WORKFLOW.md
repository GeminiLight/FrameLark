# 以照片和当前问题为主的工作流

首次打开先添加照片，也可以试用示例或打开文件项目。导入、连接模型和修改调整目标只准备本地上下文，不自动发起完整审片。完整审片保留在“详细分析”，由用户主动触发；批量分析入口仍可使用。

默认进入“对话修图”。用户描述想改哪里，顾问返回最终且已通过校验的建议后，自动打开实际像素对照；未完成的流式文字不会生成可应用操作。用户切换照片、修改画面或目标、更新批注、打开其他弹窗、进入其他工具或已开始输入下一条消息时，不自动弹出比较。

照片旁保留当前有效建议的“比较效果”入口。预览中提供“应用调整”和“应用并导出…”，后者应用后打开导出设置，不自动跳过格式与尺寸选择。用户仍可取消、手动微调或撤销。文件项目仍使用共享候选和 revision/selectionHash 校验。

主入口为“对话修图、手动调整、详细分析”，快捷键对应 1、2、3。学习、偏好、模型设置、文件项目与帮助集中在“更多”。保留原有暗房配色和系统中文字体，桌面并列照片与对话；窄屏保持完整照片比例并缩小展示高度，不裁切照片来适配界面。

验证包括新照片本地上下文、更新目标后保留已应用像素、过期回复与输入中状态不抢占预览、键盘导航，以及实际 HEIC 导入和浏览器操作。
