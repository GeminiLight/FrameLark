# 以照片和当前问题为主的工作流

首次打开先添加照片，也可以试用示例或打开文件项目。导入、连接模型和修改调整目标只准备本地上下文，不自动发起完整审片。完整审片保留在“审片”，由用户主动触发；批量分析入口仍可使用。

默认进入“顾问”。用户描述想改哪里，顾问返回最终且已通过校验的建议后，自动打开实际像素对照；未完成的流式文字不会生成可应用操作。用户切换照片、修改画面或目标、更新批注、打开其他弹窗、进入其他工具或已开始输入下一条消息时，不自动弹出比较。

照片旁保留当前有效建议的“比较效果”入口。预览中提供“应用调整”和“应用并导出…”，后者应用后打开导出设置，不自动跳过格式与尺寸选择。用户仍可取消、手动微调或撤销。文件项目仍使用共享候选和 revision/selectionHash 校验。

右侧入口为“审片、精修、风格、顾问”，快捷键对应 1、2、3、4。风格有独立面板，推荐与收藏直接可见；顾问仍是添加照片后的默认工作方式。左侧保留“图库、修片、学习、偏好”，左下角“我的”打开个人档案与成长记录。模型设置、文件项目和草稿位于齿轮“工作台设置”，不收起主要创作入口。手机底部保留“图库、修片、学习、我的”，设置位于照片栏右上角。保留原有暗房配色和系统中文字体，桌面并列照片与对话；窄屏保持完整照片比例并缩小展示高度，不裁切照片来适配界面。

验证包括新照片本地上下文、更新目标后保留已应用像素、过期回复与输入中状态不抢占预览、键盘导航，以及实际 HEIC 导入和浏览器操作。

## 默认值与保存边界

- 导入、修改目标、连接模型不自动发起完整审片；已有调整保留。
- 快捷 Codex 连接沿用已有档位，首次使用采用标准默认配置，记住配置由用户选择。取消或超时后，旧任务结束才允许同张照片重试。
- 命名版本可保存、改名、恢复和同倍率 A/B 比较；原片也可参与比较。保存版本不改变当前画面。
- 转为文件项目时，当前编辑、批注与最多 40 个命名版本一起提交。失败保留网页草稿；等待期间的新修改继续保存。
- 本机另一处修改项目时，空闲页面自动读取；尚有本地修改时保留它们并提示冲突。
- 顾问的批注、连接提示和对话位于同一阅读区域。输入框固定在下方；无批注时收起空栏，手机与短屏幕保留阅读空间。

这轮修复针对 PR #3–#7；原功能贡献来自 Yijie Xu（@yeahjack）。技术检查与适用边界见 [审核修复记录](PR_REVIEW_FIXES.md)。


## 复合请求与清晰预览（2026-10-04）

对话使用动态目录生成 `tools` 方案，每项声明工具版本、目标、参数和依赖，支持最多 24 个步骤。比较窗口可分别勾选；取消某项会取消依赖它的步骤，从固定基础重建临时方案，不改变当前照片。局部与已有标记合计最多 8 个。旧 `plan` 和单项建议继续兼容。

目标支持整张照片、区域、带明确范围的对象、批注及前一步输出。蒙版可复用；预览坐标转换一次后保存为原片坐标。本机准备图片依赖后，各步骤通过独立子进程执行，界面展示实际运行、处理和完成状态；取消会终止执行。云端使用内联编译，并如实记录执行方式。架构和扩展方式见 [工具组合](PHOTO_TOOLS_ARCHITECTURE.md)。

蒙版支持矩形排除区域。排除区内部不参与该层光色变换，过渡在排除区外侧；这是本次调整的排除范围，不是阻止未来所有编辑的永久锁。模型定位是近似几何范围，不是语义分割；可用“查看蒙版”核对绿色作用范围和未着色的排除区。Web、文件项目候选、Skill 保存与导出均携带 `exclude`。

比较画布根据屏幕像素密度从原图重新渲染，保留 100% 与同步平移。说明折叠到“参数与调整范围”，为照片留出高度。流式状态显示在正文上方，长文件名保持单行并提供完整名称提示。

Codex 档位使用账户实际返回的模型下拉列表，切换模型后同步支持的思考强度；API 接入仍支持手填模型 ID。读取列表不进行图片推理，也不改变已保存配置。

验证包含真实 Sol 复合请求、逐项取消、高清画布尺寸、390/320 宽度，以及排除区像素不变、原片不修改、候选接受与重开/导出的回归检查。
