## 用自己的照片复现

按 [中文 README 的 Web UI 步骤](../README.md#web-ui-使用) 或 [英文步骤](../README.en.md#use-the-web-ui) 创建照片项目并运行 `serve`，打开终端返回的本地地址。

1. 展开「继续精调」，修改参数或选择风格，生成试片后检查实际预览。
2. 切到原片，选择「标记问题」，框选范围并保存评论。对每个讨论位置分别添加标记。
3. 如果使用 Agent，让它重新读取项目并创建候选；如果手动修片，使用「生成试片」。
4. 选择候选查看对照，检查肤色、高光、细节和局部过渡，再接受或取消。
5. 接受后打开「导出成片」，选择用途与尺寸，实际生成文件并核对输出尺寸。

可以使用浏览器截图工具拍摄当前视口。本地地址中的会话令牌仅用于自己的编辑会话，不要放进 README、录屏地址栏或提交记录。

在线工作室是独立部署的预览；本次打开时显示 Vercel 访问保护，所以 README 的界面图来自可复现的本地 Web UI。
