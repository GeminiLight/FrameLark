Import fixtures derived from the existing public-domain NASA Eileen Collins portrait in calibration/README.md. The center crop is 384 × 512. Each JPEG encodes the inverse transform for EXIF orientations 1–8, so all should display the same upright, unmirrored portrait. PNG/WebP/AVIF are actual encoded images. HEIC, DNG, broken, empty, huge-header, over-limit and non-photo files are deliberate invalid or policy-rejection fixtures; they do not claim genuine HEIC/RAW decoder coverage. The over-limit file is sparse and rejected before any pixel allocation. Fixtures are excluded from deployment.
Large 48MP JPEG copies are valid encodings of the public portrait enlarged to 6000×8000, approximately 2MB each; these exercise decoder and workspace pixel limits, not real camera detail quality.
